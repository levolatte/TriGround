1. **实际执行链。** 区分当前源码、云端执行快照、历史代码和未执行改动。追踪审核CSV→最终英文Query/原始浮点GT→4800条顺序→提示及图像→LoRA更新→BF16推理→解析与评分；指出哪一段可由原件证明、哪一段只有报告记录。
2. **评分及比较是否成立。** 从 C0/A/B/V 原始预测重算412题和70题，不信任预测内自带IoU。缺失/非法预测是否仍留分母，坐标是否统一RGB，GT是否提前舍入，IoU边界是否一致？逐题核对A→B的3救回、10损害与47/365分组。主指标变化与框精度变化分别讨论。
3. **训练实现。** 历史C权重继承、新优化器、FP32 LoRA/梯度/Adam、BF16冻结基座是否落实？V的8个投影线性层是否真被训练并正确保存加载？语言/视觉参数组是否恰好覆盖一次？最终执行路径中的暂停恢复、调度、随机状态和消费位置有没有潜在偏差？不要将非确定差异直接断言为某个内核问题。
4. **训练数据与监督。** 最终选入题是否都来自批准版本，修正框/Query是否保留，M3FD002847用途是否正确？配对、重复上限、地点排除是否符合实际600步清单？构造的深度关系是否只涉及明确限定对象，原深度和模型可见图是否真的提供可用区分？IR题是否有额外信息证据，还是仅能找到相同对象？
5. **泄漏与独立性。** 推理输入有无GT、正确候选编号或审核答案？已知地点重用与未知地点关系如何影响解释？检查“无精确ID重合”是否被误当“无场景重合”。不要把365题或6道深度题称独立测试集。
6. **逐题失败证据。** 看图区分对象选错、同对象框不准、GT/Query歧义、输入证据不足、解析失败；只靠IoU不能下对象级判断。重点看顶灯、机器人底盘、远处小船、椅背及两道乳液；对无法目视的样本保留未知。
7. **模态收益是否真实。** 同一检查点对同题正常/置空的净救回如何变化？不存在的模态是否被排除？置空同时改图像和提示造成什么混杂？“IR置空不掉分”和“Depth6题全对”分别不能证明什么？区分模型输出响应与正确对象选择收益。
8. **能否归因。** B对A同时减少City曝光、加入多种来源/题型/缺失模式；V对B才是相对干净的视觉适配增量。当前证据能排除什么，不能排除什么？不要把B负结果直接归责于标注者，也不要猜测注意力被稀释、灾难性遗忘等机制而不提供可检验证据。
