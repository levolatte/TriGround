## 反馈揭示的问题

逐项记录见 [备注与图像复核](notes-visual.md)。这30条有备注的英文Query均直接沿用外部RoboRefIt/RGBT-GroundBench来源，未由本轮扩写；本项目的遗漏是入选前没有筛掉这些源标注问题。不能因为存在作者框就默认描述正确。

- **多余且无法证实的属性**：看不清的“维生素”“牙膏”、夜景车身颜色、模糊车牌。尤其多条MFAD题把尾灯/反光下的车辆写成红色。图中偏红不能稳定证明车身本色。
- **不可靠动作/状态**：8条拒绝涉及“停着／行走”与用户看到的骑行或道路状态冲突。后续只写可见且有区分作用的状态；不把单帧位置擅自解释成运动速度或停泊。
- **类别/框问题**：梨题框住盒子、狮子题框住体温计、自行车写成摩托车且框不完整。以上代表例已目视确认，单纯删词不能修复。
- **证据本身太弱**：有些RGB和IR都难辨，用户认为刁钻或牵强。这类题不必强行挽救。

原25题保持拒绝，不从备注推断用户批准了某种新措辞。后续新题的原则是：只保留可见且帮助绑定目标的描述；必要比较范围保留，不明确的颜色/商品用途/动作不添加。此前14题缩句退化说明不能机械缩短，并不意味着不可靠附加描述应保留。
