## 本轮处理原则

用户明确：不应将拒绝的旧题一律永久放弃；描述不准确、类别错误或框没标全的题应据图修复后重验，图像证据弱、过于刁钻的题则退出。

本轮从已归档的327题审核表中取25条拒绝记录，逐条分类；对非明确弃用项查看实际RGB及辅助图，保留真实可见且有区分作用的描述，必要时重画RGB目标框。原CSV和旧版本保持原样，修订题以新ID另存，初始状态均为待看。新审核只针对修订版本，不自动恢复旧批准，也不变更训练/诊断分组。

## 操作保持简单

复用现有审核页，显示修订后的中英题目和目标框。紧凑提示列出用户上次反馈与本次修正；仅改框题提供“查看原框”按钮。原描述继续折叠在来源区，不出现两道同时待审的Query。仍使用1保留、2剔除、3跳过，备注可选。

## 与此前实验的关系

本轮不是继续在14道深度题上调措辞挑分。此次修正来自用户指出的具体图文错误和实际图像复核：删去不可证颜色/商品用途/动作，改正类别或目标框。仍需保持修订后描述唯一，不能删去所有限定后指向多个对象。框与类别无法可靠恢复、辅助图也无法辨目标的题不强行挽救。

所有修订是候选，不是新GT已经被人审确认或模型成绩已提高。没有GPU推理、训练或比赛提交；后续仅使用修订版本实际获得的人审决定。
