## 项目地图

### 当前有实验依据的原生多图 LoRA 路线

```mermaid
flowchart LR
  A[City原始浮点标签 / 外部数据与人审] --> B[prepare_qwen3vl_native_sft 等数据转换]
  B --> C[图像路径 + human提示 + assistant千分位框]
  C --> D[prepare_gu_diagnosis 显式安排1600次呈现]
  D --> E[run_qwen3vl_native_lora.sh / Qwen外部训练模块]
  E --> F[语言注意力LoRA检查点]
  F --> G[evaluate_pretrained_grounder / 原生三图推理]
  G --> H[parse_generated_bbox / 0到1 RGB框]
  H --> I[独立浮点GT评分 / 全412与逐题翻转]
```

准确调用位置与实际训练记录见 `execution-audit.md`；数据来源、人审和显式采样见 `data-audit.md`。当前 C/M2/G/U/B/G*/U* 不经过仓库早期 `MultiModalGrounder` 的自定义融合结构。外部 Qwen 训练包通过入口脚本动态导入；其云端完整安装包和二进制权重未在本轮重新审计。

