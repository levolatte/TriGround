## 推理前固定的设计

- 样本：Depth v2全部14题、5个原train场景；目标/竞争物/参照物与原始浮点RGB框固定，不能据预测修GT或删失败题。
- 条件：long为当前proposed_query逐字保留；short为语义核对后的简洁表达。不将正常RGB/IR/Depth变化混入措辞比较。
- 模型：Qwen3-VL-8B-Instruct＋历史C（c_phase2/checkpoint-500）。单次加载并交错处理28条，成对相邻、轮换先后顺序，每条独立user message，无对话历史传递。
- 参数：原BF16路径、SDPA、TF32关闭、min/max pixels=200704/602112、max_new_tokens=128、do_sample=False。最终只要RGB框，不要求解释。
- 评分：ACC@0.5为主，mIoU与ACC@0.7同时报告；缺失、非法、解析失败不减少分母。统计短版救回与新增错误、各场景和各关系类型，保留全量逐题预测与对照图。
- 采用规则：先要求语义同目标且唯一；短版整体ACC@0.5无净损才可建议统一采用，其他指标揭示框精度代价。不得拼接每题得分更高的一版作为实测系统分数。结果后不反复改词刷这14题。
- 预算：单次对照最多30分钟；模型加载及推理实际wall time纳入既有12小时A/B/V预算。云端预检4090空闲1MiB/0%，尚无旧budget.json，预计有足够余量。

## 必须保留的语义

台阶上白衣人与黑外套者都拿瓶子，参照物须保留“把瓶子拿在背后”；前景台阶三人与背景行人分开。步道场景有四人，三对象中层题必须保留比较集合，不能只改成“找中间那个人”。相机远近不能变成与参照物的欧氏距离。简单双对象题可用自然定位短语减少冗余。

## 结论边界

这是已看过原图并人工设计的少样本诊断，不是独立测试集。14题只有5个场景，而且标签仍为代理预筛候选、用户仅做部分审核；真实人审决定尚未导入。短版改变长度的同时也改变句法与指代，结果不能单独归因于“少了几个token”。这轮不证明Depth带来互补收益，也不凭两版成败断言模型有没有完整理解句子。
