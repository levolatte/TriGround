# A/B 专项诊断：模态净收益核查

## 结论

在这 70 道配对诊断题上，**没有检出 B 相对 A 的模态净收益**。正常输入时 A 命中 57/70，B 命中 54/70；A→B 救回 0 题、损害 3 题，损害都来自标为 `rgb_sufficient` 的 Robo 题。红外置空对 A、B 的 ACC@0.5 命中均无影响；在实际执行深度置空的 38 题上，A 保留深度的净效用为 **+1 题**，B 为 **−2 题**，B 相对 A 为 **−3 题**。双置空的命中结果相同，因为此处红外置空没有造成命中翻转。

这属于小规模诊断集的描述性结果。尤其 Depth 类只有 6 题，只能逐题看，不能得出总体性能结论。置空本身造成降分，也不能单独证明模型正确利用模态；本次红外无命中效用也不能区分“RGB 线索已足够”和“模型不会用红外”。

## 口径与数据

- 使用 A、B 各自 `normal`、`ir_missing`、`depth_missing`、`both_missing` 的完整 70 行预测，逐 ID 与本地 `deployment_600_seed2026/manifests/diagnostics/gt_manifest.json` 原始框配对。预测文件中的自带 `iou`/`hit` 不参与计算。
- 按赛事材料和 `code/tools/report_triground_abv.py` 的口径，重新计算归一化 `xyxy` 框的 IoU；**IoU≥0.5 为命中**。无法解析的预测计 IoU=0。
- 模态效用定义为同一检查点的“正常输入命中 − 置空输入命中”。仅统计诊断清单标记 `intervention_applied=true` 的题。救回指置空错、正常对；损害指置空对、正常错；净效用为救回数减损害数。
- `class_map` 给出 Depth 6、IR 32、RGB 充分 32 题。`scene_map` 用于记录场景分组，70 题覆盖 46 组。IR 置空实际生效 38 题（IR 32 + Depth 6）；Depth 置空生效 38 题（RGB 32 + Depth 6）；双置空生效 70 题，其中仅 6 题同时移除 IR 与 Depth、32 题只移除 IR、32 题只移除 Depth。

## 正常输入：A→B 配对

| 类别 | 题数 | A 命中 | B 命中 | A→B 救回 | A→B 损害 | 净变化 |
|---|---:|---:|---:|---:|---:|---:|
| Depth | 6 | 6 | 6 | 0 | 0 | 0 |
| IR | 32 | 26 | 26 | 0 | 0 | 0 |
| RGB 充分 | 32 | 25 | 22 | 0 | 3 | −3 |
| 合计 | 70 | 57 | 54 | 0 | 3 | −3 |

A、B 正常预测框有 65/70 题不同，但命中变化只发生在下面 3 题。因而多数坐标变化没有带来 ACC@0.5 收益。正常输入的平均 IoU 分别为 A 0.7121、B 0.6769；此指标只作辅助描述。

## 同检查点的模态净效用

| 请求置空 | 实际生效题数 | A 置空→正常：救回/损害/净 | B 置空→正常：救回/损害/净 | B−A 净效用差 |
|---|---:|---:|---:|---:|
| IR | 38 | 0 / 0 / 0 | 0 / 0 / 0 | 0 |
| Depth | 38 | 1 / 0 / +1 | 0 / 2 / −2 | −3 |
| IR+Depth | 70 | 1 / 0 / +1 | 0 / 2 / −2 | −3 |

按能力组细分，Depth 6 题对所有置空条件、A/B 均无命中翻转。IR 32 题移除红外后，A/B 均无命中翻转。RGB 充分 32 题移除深度后，A 救回 1 题、损害 0 题，B 救回 0 题、损害 2 题。红外置空虽无命中翻转，实际生效的 38 题里 A/B 各有 29 题预测框改变；这只能说明输入和/或提示语变化影响坐标，不能据此认定红外产生有效定位收益。未实际生效的单模态置空各有 32 题，其预测框与正常输入完全相同，未混入效用分母。

`rgb_sufficient` 是诊断清单的分组标签，不应当作这些题已被实验证明仅凭 RGB 就能解决；鼠标题在 A 上反而呈现正向深度效用。

## 决定净效用差的三题

以下 IoU 顺序为 `A 正常 / A 去 Depth / B 正常 / B 去 Depth`；双置空时这些题实际也只移除 Depth，命中判断相同。三题恰好也是全部 A→B 正常输入损害题，各使“B−A 深度净效用”减少 1 题。

1. `abv:diag:robo:0004596:diag_aux`，Query：`fetch the black and gray bluetooth mouse`。IoU 为 **0.97285 / 0 / 0 / 0**。A 保留深度时正确、去深度后错误；B 正常和去深度都错误。故这题说明 A 的一个正向深度效用在 B 消失，**不能说 B 的深度输入直接导致它出错**。
2. `abv:diag:robo:0007227:diag_aux`，Query：`would you pass me the dabao body lotion on the right`。IoU 为 **0.91581 / 0.88453 / 0 / 0.94264**。A 有无深度都正确；B 保留深度错误、去深度后正确。B 在本题的深度净效用为 −1。
3. `abv:diag:robo:0007353:diag_aux`，Query：`will you please bring me the dabao body lotion on the right`。IoU 为 **0.87756 / 0.87751 / 0 / 0.88704**。A 有无深度都正确；B 保留深度错误、去深度后正确。B 在本题的深度净效用为 −1。

两道乳液题的 Query 相近，但在 `scene_map` 中属于不同场景。上述计数针对题目而非模型独立重复实验；不能把两题当成强独立性证据。

## 判断边界与后续

这批干预同时把相应图像替换成全黑占位图，并在提示语中说明模态不可用，因此观察到的是“图像+提示语”联合干预的效果；不能严格分离纯视觉模态的因果贡献。诊断样本仍少，Depth 组 6 题尤其不足。当前证据支持“B 在这批专项题上没有增加有效模态净收益，而且正常命中少 3 题”；不能外推为 B 在所有赛题上更差。普通训练带来的 City 整体分数变化应单独用完整 City 配对评估，不能当作专项模态收益。
