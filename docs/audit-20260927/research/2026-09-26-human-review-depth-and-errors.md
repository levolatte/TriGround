## 2. 对Depth方向的修正

用户指出的问题成立：此前大量工作验证的是“这个物体能否在Depth中对应到区域”，却没有充分训练“利用Depth区分竞争对象”。这两种能力有联系，但前者的高通过率不能代替后者。

下一批优先从已有City训练图中选择中近景、多对象、有明确前后层级的场景。保留RGBDT可靠对应任务；其深度方向尚未确认的部分不自动生成近远标签。Robo同样不能凭灰度观感断言数值近远。

本轮实际检查现有80组City训练图，留下6组、15个原目标作为进一步出题候选，其中3组可比较三层、3组可比较两层。例如红车、银色面包车、后方黑车的中心区域读数约6.6、8.3、13.2米，图像也可见相应前后遮挡关系。仍需制作方核对主体取样和背景，不能仅凭框内统计放行。

三只熊的训练图 `000016_034_00000199` 是一个反例：原描述依赖左下角、坐姿和靠墙，框内收缩区域读数约5.2、6.1、7.0米，但Depth预览在熊和地面之间看似连续平面。这组三熊已暂缓、未进入6组候选；数值有顺序也可能是地面梯度，并不证明测到了熊。后续由制作方先核查主体小块及邻接背景，再提交必要的抽验，不要求用户重做全图分割。

建议围绕一组经确认的对象派生三种短答案任务：

1. 给两个候选，判断哪个更靠近相机，输出编号。
2. 给三至四个候选，由近到远排序，输出编号序列；深度接近时允许“无法可靠区分”，不强排。
3. 用自然Query选择某一层级，例如“两只黑熊中离相机更远的一只”，最终输出RGB框。

IR与Depth的组合题可使用“先通过RGB/IR识别并确认同类候选，再按Depth层级选目标”的结构。是否确有IR额外线索仍须逐图核对，不能为了三模态名义强加热源或距离条件。

制作要求：候选编号随机化；不把距离答案或排序作为输入；保留原标签另加派生任务；深度可靠性检查使用对象内部区域并结合图像确认，记录无效值、分布宽度与候选重叠。避免把地面纵向梯度、画面上下位置、对象大小直接当作近远答案。已知左右关系不能代替深度层级题。

首批小试验使用已验收181条，不等待新的大池。深度层级候选单独整理，可靠部分加入下一次小规模对照，避免第一轮同时更换数据、模型架构、像素与优化器设置而无法解释结果。

## 3. 旧模型真实错例

使用同一4090机器的完整412条验证结果，原始浮点GT和ID完全一致：R2=286，M2=285，C1500=292。三个模型共同正确273、共同未命中110。M2相对R2纠正11、退化12；C相对M2纠正9、退化2。

共同未命中样本的GT面积中位数为画面0.147%，共同正确为0.622%。小目标与失败相关，但这个统计本身不能证明缩图是唯一原因。

已从云端取回16图组的RGB、IR、原始Depth及实际模型Depth输入，共64张原图，逐图核对并生成图册。每例包含目标、R2/M2/C框、放大图、英文Query及中文解释。选择涵盖三者都错、三模态退化、C纠正和C退化，不是随机抽样，错误类别比例不能外推全验证集。

| 实例 | 应定位/实际预测 | 更直接的问题及改进方向 |
|---|---|---|
| 中央路灯旁远处行人 | R2命中；M2/C选右侧其他行人 | 极小同类实例，目标Depth无有效值；需要同类参照训练和局部辨别，不能指望补深度排序解决所有远人 |
| 右边缘深色汽车 | R2命中；M2/C选被画面截断的邻车 | 颜色、边缘位置与同类干扰；核对Query约束并训练候选比较 |
| 栏杆后深衣人 | 三者选同一人，M2/C框延至栏杆下 | 可见部分/整物体的框范围问题，需统一监督口径 |
| 窗户反光条 | 三者找对同一条，C框略矮，IoU从M2约0.515降至0.480 | 边界失分，不应描述成模型认错对象 |
| 紫色玩具旁的小车 | R2选左车，M2/C选右车，两侧都有车 | “旁边”未限定方向，Query有歧义嫌疑；保留原分数，独立记录复核意见 |
| 红桨板左侧的人 | 三者找对同一人，框偏窄，IoU约0.48 | 精细边界、阈值附近误差，Depth不是首要补救 |

16例中7例GT区域原始深度正值占比为0；这只是精选样例的输入观察，不是全体比例，更不能据此宣称Depth导致错误。IR中也有过小或难分的目标；存储亮度并不等于标定温度。已有人类观察支持的数据问题、实例混淆和框边界问题需要分别处理。

## 4. 按收益组织下一步

**数据第一优先：**建立可靠层级任务，配合同类干扰、明确参照、组合/部件框范围任务。先用少量高质量对象对验证训练信号，再增加数量。当前181条偏向跨模态对应，可以测试这种监督是否有用，但不能作为深度推理能力的完整训练集。

**模型训练第一优先：**保持8B和已有LoRA配置，在相同底层场景、样本呈现次数和更新数下，对比“全直接定位”与“定位+对象对应/候选关系”。最终定位仍输出RGB框。深度层级题单独记录效果，防止辅助题答对但实际定位不变。首轮采用已批准的小规模成对试验；不自动恢复1500更新长跑。

**算法小实验：**把实例选择和边界细化分开。候选区域可靠时，可比较候选表不带深度与带可靠顺序两种输入；候选必须来自实际推理，GT只能用于训练标签和评分，不能拿GT候选的成绩当端到端结果。小目标可另试同位置三模态局部放大并保留全局参照，恢复坐标后再评分；不能只按GT位置裁图当成绩。两项均是待测方案，未声称已提升。

**模态使用原则：**Depth有效且对象层级可区分时使用其顺序；Depth缺失、同层或无法可靠分离时，不强行推断近远。IR目标对比更清晰时用于识别或轮廓；颜色和文字约束仍回到RGB。需要学习何时信息可靠，而不只是固定拼三张图。

评估保留完整412分母及原标签，另列“实例错误/边界错误/输入缺失/描述歧义”诊断。疑似Query或GT问题先记录、不直接改分。新的训练只能取训练划分；错例图册来自验证集，仅用于分析，不回灌这些图制作训练题。首轮训练仍需GPU恢复和16微批、2更新、保存重载检查。
