# 三图无净增：证据与待区分原因

本次结论仅限原生Qwen3-VL-8B、语言q/k/v/o LoRA、3707训练/412验证、2轮seed2026、固定像素602112配置。R2/M2固定epoch2均288/412，不等于证明IR/Depth无信息。

## 已核对事实

- 412条M2真实推理记录全部具有三个[1,36,64]视觉网格；R2全部一个，目标框412条一致。
- M2正式训练日志可训练30,670,848参数（语言LoRA），288/288参数张量得到梯度，完成928次更新。
- 两组配置文件差异仅数据集名、训练清单、输出目录；同基座、seed、轮数、学习率、像素、优化器和数值设置。
- R2/M2共同对277、共同错113、R2独对11、M2独对11。仅62条预测框完全相同，350条有坐标变化。变化不能单独归因于模态信息，模型权重/提示也不同。
- 固定epoch2净增0，图组bootstrap ACC差95%区间约[-1.97,+2.07]百分点。一次seed不能分离训练随机性；也没有大幅正收益的实测证据。

## 尚未验证的原因

1. 视觉输入进模型不等于模型有效使用IR/Depth。视觉编码器冻结，只做语言层LoRA，可能形成RGB主导的决策；需同一M2检查点的模态干预测试。
2. 同一bbox监督没有明确要求用深度或红外。额外模态若在多数Query上冗余，新增信息不足以抵消混淆；681训练图组也限制独立场景覆盖。不能据此直接断言标签有错。
3. 固定深度可视化的有效动态范围、IR/RGB对齐、模态特有可判别目标比例尚需针对性分析，而非全面重做数据检查。
4. seed仅一组，存在波动；不应只换seed碰涨分。先用低成本干预定位机制，再决定成对复验。
