# G/U 新数据小试验退化归因审计（412 条全量）

2026-09-26；仅离线 CPU 统计和原图核查。未训练、未改 GT/Query、未触发推理或新提交。

## 结论与可识别边界

1. **不能笼统说“新数据使总体 ACC 退化”。** 固定 200 更新后，G200=288/412、U200=283/412；相对初始化 M2=285/412，分别是 **+3、−2**，图像组自举区间都包含 0。相对 C1500=292/412，分别是 −4、−9，平均 IoU（交并比）也低 0.0192、0.0174；但 C 的训练量/轨迹不同，此比较证明当前候选没有超过较强的既有模型，**不能归因为辅助标签本身有害**。
2. **G/U 的共同变化兼有局部框收缩和少数实例区域跳变，单一解释不够。** 相对 M2，G/U 的预测框面积中位比为 0.966/0.979，中心位移中位均约 0.00071（归一化坐标）。G/U 各有 393/395 条预测框与 M2 的相互 IoU≥0.7；在这部分，平均 GT IoU 仍下降 0.0068/0.0052，说明损失并非只来自少数换实例。另一方面，G/U 相对 C 各有 18/17 条预测框相互 IoU<0.5，包含明确邻近实例错选，贡献 C→G/U 连续 IoU 净损失约 41%/42%。数值的“相互 IoU<0.5”只是筛选线索，不能逐条当作实例错选标签。
3. **G 与 U 直接配对不支持“U 普遍学坏目标选择”。** U 相对 G 少 5 个 ACC 命中（纠正 1、退化 6），但 412 条平均 IoU **高 0.00180**，162 条提高、110 条降低、140 条近乎不变；两组预测框 401/412 相互 IoU≥0.7。七条 ACC 翻转位于相同目标区域附近，主要是框边界跨 0.5，斑马等重叠实例的标框范围仍有歧义。U 的框相对 G 反而稍大（面积中位比 1.010），不能据这 7 条称 U 整体更“缩框”或目标选择明显更差。
4. **坐标量化会放大小目标误差，但不是当前整体退化的充分解释。** 将原 GT 四个坐标各理想地四舍五入到 0.001 再还原，412 条仍全部≥0.5；平均 IoU 0.978、最小 0.853。最小面积四分位的平均 IoU 为 0.953，35 条低于 0.95 的样本中 34 条在该四分位。这只是使用 GT 的几何诊断，不能作为模型可达到的成绩。相对 M2 的平均退化主要出现在中间两个面积四分位，最小四分位的 G/U 反而略增。

## 口径、数据与独立核算

- 官方 `contest/基于大模型的多模态视觉理解与推理.pdf` 第 4、6 页规定：BBox 是可见光图像上的归一化 `[x1,y1,x2,y2]`，主指标 ACC@0.5 按 **IoU≥0.5** 判定。这里是内部 City 固定验证集 412 条、78 个图像组，**不是官方测试成绩**。
- 直接读取 `results/next_stage_20260925/{baseline_m2,c_step1500}/predictions.jsonl` 与 `results/gu_pilot_20260926/final_cloud_snapshot/{g,u}_2026_city{100,200}/predictions.jsonl`。六份均为同 412 个唯一 ID；逐 ID 的 Query prompt、GT 一致，所有预测均解析且框合法。独立用原预测框与文件中的 GT 重算 IoU；与保存的浮点值最大差约 0.0000046，无一条 0.5 命中状态受影响。边界例 `city_002509_001` 的 U200 IoU=0.499963，仍判错。
- 原报告的 78 图组 10,000 次自举区间在 `results/gu_pilot_20260926/final_cloud_snapshot/report_2026/report.md`。本报告以同一 412 条按 ID 配对，另算连续 IoU、预测框相互 IoU、面积/中心差、GT 面积分位与文字触发词；完整数值和每个翻转 ID 在同名 `.json`，可用 `python code/tools/analyze_gu_outcome_20260926.py` 重算。面积四分位阈值为 0.001428、0.004059、0.015885，各 103 条。文字触发词是粗略词面代理，多个类别会重叠，不代表真实关系推理标签。

G/U 相对 M2 有明显的面积收缩方向：相差超过 5% 的样本，G 有 165 条收缩、22 条扩张；U 为 122 条收缩、24 条扩张。宽/高比中位 G=0.985/0.986，U=0.993/0.995；中心横、纵位移的中位皆为 0，未见一致的全局平移。G/U 相对 C 的同向面积变化也存在，但 C 的不同训练史阻止将其单独解释为新数据所致。G 相对 U 更小，且后 100 更新 G/U 平均 IoU 都没有明显提升；G 的 ACC 从 284 到 288 是四条跨阈值，平均 IoU 反而微降 0.0009。

从损失结构看，C→G 有 7 条 IoU 下降至少 0.3、12 条下降 0.1–0.3；C→U 分别 7、8 条。G/U 相对 M2 均无 IoU 下降至少 0.3 的样本。以 M2 为更可比的起点，G/U 与 M2 **预测框高度重合**的 393/395 条平均 IoU 下降 0.0068/0.0052；相互 IoU<0.5 的各 8 条净贡献反为 +0.612/+0.945 IoU 总和。因此，若说“新数据主要学坏了实例选择”，会误读 M2 对照。以 C 为参照时，低相互 IoU 的 18/17 条贡献 −3.228/−2.980 总 IoU（净差 −7.918/−7.177），约 41%/42%，余下连续小损失同样重要。分组是结果条件化后的描述，不作因果估计。

一个不拟合超参数的几何核查：只把 M2 的宽、高移到 G/U 的中心，G 的平均 IoU 仅增 0.00366、ACC **少 2**；U 的平均 IoU 增 0.00077、ACC 多 1。把 C 的宽、高移到 G/U 中心，平均 IoU 分别增 0.00852/0.00543，但 ACC 只变 0/+2。此操作需要参考模型在评估时的预测，也会与中心和实例错选交互；它只说明面积差能解释部分连续 IoU，**不能当作验证集调出的可部署缩放修正**，更不能单靠缩放解释官方 ACC 落差。

## 阈值翻转、原图与尚未目视的连续错例

G→U 七条翻转中，五条在双方 IoU 均距 0.5 不超过 0.1 的窄区间；另两条为 `city_000012_022_00000090_001`（0.392→0.543）和遮棚斑马 `city_000023_001_00000001_001`（0.650→0.495）。斑马原 RGB 局部图的 GT 较宽、跨两只重叠斑马区域；G 较宽、U 较窄，目标是单只还是遮挡下的可见部分、GT 标框范围不能仅凭预测框裁决。七条均位于所描述目标区域附近，现有目视审阅支持“主要边界翻转”，并保留这类语义/框口径不确定性。`city_000081_006` 的 0.5026→0.4947 显示极小边界变化即可扣 1 个命中。

旧 30 例审阅（`results/gu_pilot_20260926/atlas_final200/failure_review.md`）已经记录灯柱、上下顶灯、栏边动物、相邻访客等 C 正确而 G/U 改选附近实例的例子；`city_hehe_230_000002_043_00000061_013` 反向由 C 错选旁人变成 G/U 选中目标，故非单向崩坏。另在全量连续 IoU 中发现不跨 0.5 的例子 `city_000019_038_00000205_007`：Query 为“站在戴口罩访客旁的黑发人”，GT x=0.8406–0.8734，C 框 x=0.840–0.876（IoU 0.450），G/U 框移至 x≈0.891–0.934（IoU 0）；原 RGB 右侧确有邻近访客。这条不在 30 例图册中，说明只审命中翻转会漏掉实例区域变化。

C 与 G/U 预测框相互 IoU<0.5 的并集共 20 条：旧图册已目视 8 条，本次补审其余 12 条，本地原图现全部齐全并已目视。新增 12 条中，3 条确认预测移到相邻目标区域，2 条密集车组有实例边界/序数争议，2 条落到不同对象或结构，2 条主要是语义或组合框口径争议，**另 3 条虽数值相互 IoU 低，实际仍在同一错误候选区域内微移**。`city_000066_005` 的 C/G 框相同、U 仅左移约 13 像素，小框尺寸使相互 IoU 接近 0；不能将其自动解释为换人。逐例证据见 `results/gu_pilot_20260926/low_agreement_review12/visual_review.jsonl` 和 `visual_review.md`。因此 20 条现全部有原图目视记录；仍不能把它们全部宣布为“选错实例”。对全部 412 条已有几何统计，但未作全部原图的人类身份判定。此子集按结果定向挑选，类别频率不可外推至全体验证集。

## 图组、尺寸与 Query 词面分布

相对 M2，G/U 的平均 IoU 在第 2/3 面积分位下降约 0.0103/0.0117、0.0107/0.0087；最小分位为 +0.0010/+0.0066，最大分位为 +0.0053/+0.0044。相对 C 的第 2 分位均约 −0.049，四分位中的低相互 IoU 也主要集中在前两档；但这仍与 C 训练量不同混在一起。78 图组里，相对 M2 有 44/45 组均值下降，说明变化不是一个图组造成；图组内 Query 有相关性，不将 412 条当作独立场景。

词面标志有“序数/极值”84 条、“空间词”285 条、“关系词”156 条，彼此重叠。G/U 相对 M2 在序数词子集平均约 −0.010，空间和关系子集略低；G→U 在这三子集平均分别 −0.0006、+0.0026、+0.0015，而 ACC 变化分别 −2、−5、−4（重叠不可相加）。数量少、词面粗、反复看多个子集，不能称某种关系推理或某个模态受损，更无注意力机制证据。

## 下一步最小区分试验（建议，未执行）

1. **纯 CPU 低框重合核查已完成。** 并集 20 条全部有原图目视记录，其中新补的三组证明“预测框彼此 IoU<0.5”会因小框内微移而发生，并不必然表示改选目标。个别极远目标仍无法精确辨认身份；不改原 GT，不将此定向子集的类别比例外推到 412 条。
2. **若之后允许 GPU，再做匹配的 200 更新 City-only 对照和另一 seed。** 保持 M2 初始化、优化器/学习率/City 呈现位置与评估协议一致；只替换原每 8 条中的 2 条新任务位置为预先固定的 City 样本。City-only→G 对比检验新增任务加上数据配比的净影响，G→U 在原成对轨迹上检验输出类型影响。至少另一 seed 才能判断当前几条 ACC 差值是否稳健。这仍不能把“训练样本来源”和“City 重复暴露量”完全拆开，若需纯来源归因还要更严格配比设计。当前门槛未达，不自动启动这些试验。
