## 研究问题与对照

保留历史 A（它本身使用多模态）作为只读原定位器。第一次调用 A，产生真实 RGB 建议框和完整 Query 的提示末端表征；第二次调用独立修正分支。比较：

| 模型 | 第二次调用 | 最终框 |
|---|---|---|
| A | 无 | 原定位输出 |
| R | 从 A 初始化的独立语言 LoRA，完整 Query、原视图、实际建议框 | KEEP 复制 A 原文与原框；REPLACE 使用文本框 |
| S | R 加模态私有入口、数值 Depth、对象条件读出 | 同 R 的文本解码 |
| S+G | 与 S **完全相同的第二次调用、同一组 S 权重** | KEEP 仍复制原框；REPLACE 使用连续几何头 |

S 与 S+G 同时导出，不增加第三次大模型调用。R/S 分别训练，使用相同数据、样本顺序和正式步数。GT 只进入监督与评估，不作为模型建议框、提示区域或推理参照框。非法修正计失败，不回退为 KEEP；所有题保留在分母中。

## 已实现结构

原生 Qwen3-VL 的主视觉出口和三个 DeepStack（深层视觉注入）出口均接入结构。IR、Depth 各自使用四个私有低秩残差：rank=8、alpha=16、dropout=0.05，上投影初始化为零；RGB 出口保持原路径。图像槽位、视觉 token 数量和位置编号均不改变。

已知毫米 Depth 增加 7 个特征：统一尺度的 log 深度均值、标准差、可用比例、近距比例、饱和比例、二维位置。编码器为 7→128→128，四路输出投影均初始化为零。工程可用掩码按本轮计划采用 `0<d<19999`；正值且小于300单独标记，19999及以上标记饱和。这是本轮编码策略，不把小于300宣称为官方有效测量。缺失/退化 Depth 同步停止读取数值支路；未知编码的 Robo 数据不套用毫米规则。

对象读出宽度256、4个注意力头、每种模态2层。目标和最多两个参照槽先读 RGB，再分别读 IR、Depth；使用独立 sigmoid（S形函数）门控，起始值0.5，证据输出投影为零。门控表示内容选择，不是校准后的正确概率。监督只使用已有核准区域；两个无序参照通过最小匹配损失绑定，不能把参照顺序当作标签。小于视觉 token 的框按覆盖比例监督。

G 使用 S 的**答案生成前**提示末端表征、四路原 RGB 空间特征和真实 A 框，经过两层跨注意力预测中心、宽高的连续残差。输入全部截断梯度，输出零初始化。损失为 `5×L1 + 2×(1−GIoU)`，G 使用独立优化器、独立梯度裁剪；G 前向无随机丢弃。S 的文本结果与 S+G 的框结果因此可直接配对比较。

实际基座配置的隐藏维度为4096。新增可训练参数：S 模态结构 **17,952,642**，G **6,828,036**；不含已有语言 LoRA。结构配置与真实参数分别保存为 `structure_config.json`、`structure.pt`，加载时严格匹配。

主要代码位于 `F:/AIC/code/tools/`：`grounding_structure.py`、`structured_grounder.py`、`train_grounding_structure.py`、`cache_grounding_proposals.py`、`evaluate_grounding_structure.py`、`run_grounding_structure.py`、`report_structure_results.py`。

`structured_grounder.predict_two_calls` 是不依赖离线缓存的在线入口：加载默认A与revision修正适配器和结构后，显式切换、冻结两套适配器与新增模块，实际执行A→修正两次生成，返回R或S/S+G结果。8B零步检查也通过这个入口验证A保持不变；正式对照评估复用同一A缓存以减少重复计算。
