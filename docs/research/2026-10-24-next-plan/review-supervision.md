# 新监督与训练路线的反方审查

2026-10-24。只审查技术路线，不修改模型、训练脚本或旧报告；本轮没有训练或推理。依据当前91条复核、[历史](../2026-10-23-reassessment/history.md)、[既有文献审读](../2026-10-23-reassessment/literature.md)，并独立阅读下述两篇论文的方法与消融。

**建议保留27B原生三图、单次直接出框。下一步最值得检验的新监督是“同图竞争框为何不合格”，而不是增加一段解释正确框的文字。先确认这种监督迁移到无候选的直接出框，再决定短框RL或视觉侧改动。两者不应未经诊断串成必经流水线。**

## 1. 现有证据允许说到哪里

91条是旧标签下筛出的失败子集，涉及42张图像；44条模型问题、33条参考框问题、31条Query问题是初步复核的重叠计数，不能当作总体错误率。#26的“跨人混入”指控在精细复核中已撤回，不能继续作为该机制的证据或训练负例；最终数目应引用标注修订结果。

用户已明确本轮只修91条，不扩查321条命中。本报告不沿用旧README中“必须同时审查321条”的建议。修订91条改善的是局部诊断依据，不能据此宣称412条都已审定，也不能把修订参考框带来的重算变化写成模型进步。

更直接的机制线索是：双头灯只取一头、遮挡两侧可见身体漏一侧、漏尾；相邻同类目标和多个约束冲突；以及辅助模态中的主体信息确实缺失或混入背景。它们至少包含“实体范围归属”“目标身份/约束绑定”“证据可用性”三个不同问题，不能统称坐标不准。

## 2. RGBX-R1与Perception-R1没有形成可直接套用的二选一结论

[RGBX-R1，§3–4、附录3](https://arxiv.org/html/2602.00504v1)使用目标模板与多帧RGBX定位。表1中普通SFT、仅CoT冷启动、普通SFT加后续强化、完整流程的平均分依次为31.04、19.64、32.74、46.53。其模态奖励包含与参考推理的token匹配，时间奖励加权后续帧；深度提示为近暗远亮。这个结果支持作者的组合流程，不保证只加CoT有效，更没有证明移除推理文本后仍有增益。

[Perception-R1，表5](https://arxiv.org/html/2504.07954)的RefCOCO无思考/有思考为89.1/75.1，SFT/RL/SFT+RL为88.2/89.1/88.4。该实验支持短答案感知策略，却不覆盖本项目真实红外、失效深度和复杂参照关系的全部学习问题。

**本项目推断：**两者的基座、输入、任务与奖励不同，不能用一篇“推翻”另一篇。应借鉴RGBX-R1关于模态知识缺口的假设、Perception-R1关于短输出的对照意识；不复制模板、多帧、参考推理匹配或时间奖励。本项目近亮深度表示也不能沿用其近暗提示。

更强的反方问题是：如果辅助模态证据本来就不存在，教模型说“红外辅助识别、深度验证距离”只会训练事后解释。如果证据存在，却没有教对象与区域对应，长文字同样可能绕过真正缺口。反过来，单次短框任务也可能受益于训练期的中间监督；Perception-R1不能否定这种迁移，但迁移必须单独检验。

## 3. 最小真正新增的监督目标

建议把首轮新增目标限制为一个：**候选框对当前Query是否语义合格，以及不合格的决定性原因。** 直接框SFT只告诉模型正确答案；这个目标增加“这个相似答案为什么不能选”的监督。

每个来源可靠的外部训练图组，保留原生`三图 + Query → 正确框`，另给少量同图候选判别训练行：输入相同全图、Query和A/B坐标，输出选择及一个短原因标签，例如`B; A=missing_visible_part`。它不是自由生成CoT，也不是部署时的第二个裁判。

| 因素 | 有效监督 | 不足以自动构造监督的线索 |
|---|---|---|
| 同一实体 | 可靠实例身份/掩码或回图核实：A是目标，B是相邻同类个体 | IoU高低不能证明身份；人框与骑乘物重叠尤其如此 |
| 完整可见范围 | 已确认属于同一实例的尾、另一灯头、遮挡另一侧可见身体被候选漏掉 | 对正确框随机缩小不必然截掉可见对象；也不补猜测的不可见身体 |
| 明确Query条件 | 已标定目标、参照物和候选集合后，确认候选违反左右/序数/关系之一 | 只改left/right或序数词可能造出无目标、多目标描述 |
| 模态证据 | 主体区域的IR可见性、有效深度及可辨关系；不知道就标未知 | 全框非零深度、热斑亮度、模态名称均不能证明目标证据有效 |

首轮以身份/完整可见范围为核心；关系和模态项只有现成可靠标注时才加入，不能为了凑齐字段自动编造。`unknown`是辅助任务的有效标签，不代表最终任务可以不交框。

**必须修正一个容易造错负例的规则：矩形中出现另一人的像素，不等于框把两个人合并。** 轴对齐框会包含空白、遮挡物和邻人；只有证据显示边界被错误地延伸到别人的肢体，才能判定错误范围。#26撤回恰好说明这一点。牌面/带杆、单灯头/整灯也须先确定目标单位，不能用统一扩框替代语义。

IoU≥0.5只是定位评分阈值。一个截断框可能过阈值，一个正确小目标的略松框可能不过阈值；辅助标签必须来自身份、可见范围及描述条件。未知、两个候选都错、两个都可接受的情况须保留对应状态，不能强制二选一造假标签。

### 能否迁移到单次直接框

**可能，但现在没有证据保证。** 给定候选后判断好坏，省掉了生成候选和搜索目标的工作；模型还可能利用面积、中心位置、候选顺序等捷径。因此直接框训练行必须保留，主评估必须用原生无候选提示。A/B准确率上升只说明辅助任务学会了。

随机交换A/B，并在数据中包含“大框更好”和“小框更好”、高IoU但语义错误、低IoU但同一实体等真实情况，避免把任务化成选大框或坐标距离分类。不要在教师输入里展示GT后，让教师“验证”自己的解释，再把一致性当独立正确性。

若后续发现A/B学习明确但完全不迁移，更直接的替代是：在原生无候选输入下，让同一模型对正确框答案与已核实错误框答案做成对偏好优化，并保留正确框SFT锚点。它让训练输入贴近部署，但仍有数字token概率与几何语义不等价的问题。**首轮不同时引入A/B、偏好损失和新连接器**；否则无法判断收益来源。

## 4. 数据和目标结构如何避免重做旧8B Agent

只用一个27B策略、固定一次观察、固定RGB全图坐标系。候选和区域标记只属于训练辅助任务；部署仍是原生三图和Query直接生成一个框。没有Search/Depth工具链、控制器、动态裁剪和多模型裁判，不恢复已退役专家。

数据最小记录包含：来源与场景/序列ID、目标单位、原生Query与正确框、同图竞争框、短错误标签、该标签的依据。已有可靠数据可以派生判别行，但派生行不是新独立场景。同图与视频邻帧必须在同一分组；训练中控制每个图组的重复，而不是按JSON行数夸大数据量。

优先复用外部训练数据的已有实例/分割/关系信息；缺少目标归属时，框扰动只能生成待确认候选。当前91条用于理解错误和局部诊断，不把其修订记录直接回灌成训练答案。独立外部场景留出集同时包含可靠成功与失败例，避免只看救回这91条；这不要求审查原321条。

辅助模态数据必须保持配对和各自坐标对应。目标在IR中可见不代表IR框与RGB框数值完全相同；未核对配准不能复制区域或把同位置热斑当身份。深度只在主体有效区域比较近远，背景、前景杆、水面和零值分别记录。未知证据与无辅助图不能伪装成“RGB已经足够”的负标签。

本项目历史Arm2已有能力混合SFT；新增图数、长Query比例或再写一遍bbox均不足以构成新的学习假设。这里新增的是可核实的错误竞争答案及其失败原因。仍需与同批数据的普通框SFT比较，不能拿旧Arm2直接对比新数据、新预算、新目标后把差值都归给目标。

## 5. 何时动视觉侧，何时直接RL

| 观察到的缺口 | 更合理的下一步 | 不能据此推出什么 |
|---|---|---|
| 同一输入下已有可靠正确短框样本，候选优劣/范围判断也大体正确，单次选择不稳 | 短框GRPO，优先检验可验证框奖励能否改善单次选择 | 有限采样中没出现正确框，不等于模型永远不可能产生；出现过也不保证RL必有收益 |
| 主体证据存在，语言LoRA后辅助判别仍失败，而给定正确区域时也读不出IR/Depth关系 | 在相同数据与目标下对比冻结视觉与小范围视觉侧训练 | 失败可能仍由数据、配准、尺度或监督错误造成，不能直接诊断编码器缺能力 |
| 各模态单独能识别给定区域，但跨模态对应或融合失败 | 优先考虑对齐层/局部跨模态连接器的受控对照 | 不能把整个视觉塔同时解冻后声称证明连接器有效 |
| IR主体不可见、Depth主体无有效值，或对象小到输入中不可辨 | 不为该样本加融合奖励；先承认观测缺口 | 连接器和RL都不能创造缺失的传感信息 |

视觉侧对照必须固定正确深度表示、原图/RGB分辨率、训练场景、目标和预算。历史Arm4/5同时改数据与视觉侧，不能作为已经完成的这种对照。

若确有结构性瓶颈，先选择一个最小变更：给定模态内信息可读但语义映射弱时试对齐层；模态内部目标表征就失败时才试局部视觉LoRA。局部RGB←IR/D连接器还需处理动态分辨率的不同网格、坐标对应和无效深度，不能直接套固定方形网格代码，也不能用整框平均深度给它错误监督。这是需要独立证明的工程投入，不是多模态任务必备手续。

## 6. 最多两个训练阶段，保留两个决定性比较

### 阶段一：新监督是否转移

从同一个27B检查点出发，先只训练语言LoRA：

- **A：**同批可靠训练图组的普通直接框SFT。
- **B：**相同图组、相同直接框基础曝光，加入上述少量候选语义判别；A在对应辅助槽位使用普通直接框行。

两臂保持相同图像呈现次数、优化步数、分辨率和可训练参数；记录因短辅助输出产生的token/GPU时间差异，不把相同步数冒充严格相同算力。总预算紧时限制辅助输出为短标签，避免长CoT把计算量悄悄放大。先不为每种标签另跑一臂。

**决定性比较：B对A的原生无候选、单次直接框结果。** 主看独立外部场景的ACC@0.5与配对净救回，另看范围/身份错误，以及可靠清晰样本的退化。按场景聚合，少数同图Query共同改善不能冒充很多独立证据。修订91条只作目标机制的补充观察，不报告成总体效果。

如果B仅提高A/B回答或短解释正确率，直接框不变或退化，则本轮“训练期辅助监督可迁移”的假设未获支持。不能用更长解释、再加裁判掩盖这个结果。

### 阶段二：只选一个瓶颈，不自动同时做结构和RL

**默认选择短框RL：**第一阶段胜出模型已能读取必要证据、可靠奖励有组内差异时，比较短框GRPO与同预算继续SFT。保留第一阶段检查点作为零追加成本基线。连续IoU可提供阈值以下差异，但只使用可信目标；二值过阈值奖励不能代替语义完整性。格式已稳定时不让格式分支主导收益。

**只有出现上节的视觉证据缺口，才把阶段二替换为视觉侧对照：**同一监督下冻结视觉vs一个最小视觉侧变更；本轮不再接第三段RL。否则“先解冻再RL”会把两种改动混在一起，超过两阶段且难以归因。

短证据RL暂不是必跑分支。如果第一阶段发现一个明确、可核实的短区域关系输出能帮助直接框，可在后续替换相应比较来检验“短框vs短证据后框”。不能同时改奖励、推理预算和输出形式；证据奖励不得按参考句token匹配，更不能奖励说出模态名称。若只能靠训练标签验证证据而推理时无法取得，须明确这是训练监督，而非部署时的独立验证器。

本路线的停止条件是机制被否定，而不是预算还没花完：没有可靠新增监督就不扩规模；只会判候选却不会直接框就不声称迁移；辅助主体信息缺失就不为它造融合知识；视觉表征能读取而选择不稳时优先短框RL，不重新搭旧Agent。
