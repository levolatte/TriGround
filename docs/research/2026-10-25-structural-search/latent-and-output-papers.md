# 区域状态、整框预测与候选分工：主论文深读

2026-10-25。本轮从 23:02（UTC+8）重新联网调查，结合全部项目路线恢复，阅读下列论文正文与附录；公开方法源码由相应专题逐项核对。本文记录机制证据，不是本赛新成绩。论文中没有公开的训练程序或权重，明确保留缺口。

## 1. ReferFlow：状态必须同时知道是什么、在哪里

[论文 v1，28 页](https://arxiv.org/abs/2610.20352)、[作者仓库](https://github.com/V-Insight-AI/ReferFlow)。Qwen3-VL-2B 在文字间维护对象索引的连续区域状态；训练时同时监督位置和区域视觉内容，推理不输入 GT 区域。最终坐标由另一个条件于轨迹前缀的分组解码过程恢复，辅助回归头在推理中移除。其主基准还提供有序步骤，不能与自由分解一条本赛 Query 等同。

关键同表证据是：无监督潜变量相对文字基线变化很小，同时加入视觉和位置监督后，GroundingME 从 32.4 到 37.4；仅改成一次并行预测会降分，分组迭代及几何约束才恢复。该表支持的是有监督的区域状态及指定解码机制，不是“把隐藏向量反馈一次就会推理”。训练约 1.6M SFT 条目；自建轨迹含检测器与大模型教师，存在教师可定位区域偏差。仓库当前仅公开说明/页面/图，不能声称源码复现。

**对项目的解释：**值得迁移的是区域状态的双重约束，以及后续决策确实消费该状态。旧 R/S 也有角色区域损失，故不能仅凭“有对象槽”宣布新路线。新设计应让状态形成于第一次目标决定之前，且从最终框损失回到目标—参照关系更新。GT crop 只能作为训练目标，绝不能给推理状态偷偷提供正确位置。长文字轨迹和固定多步奖励不是本赛目标；这里不按思考步骤数奖励。

## 2. Motto：空间锚定、回读和框解码已有直接先例

[论文 v1，27 页](https://arxiv.org/abs/2607.24407)、[作者代码](https://github.com/TG0110/Motto)。P/R 两套 token 对应 3×3/5×5 网格；模型先产生粗区域，再结合全图与聚焦区域信息回读，最后通过专用解码器预测框。训练目标包含语言、匹配分类和框损失。增量消融中普通特殊 token 的平均分 54.1，空间 P 为 56.1，P+R 为 57.3，加入其余模块到 59.4；这些是论文自身多任务指标。预训练约 7M、第二阶段约 6M 条目，消融也用 3M，不能将其当小数据适配结果。

作者公开了模型和单图推理代码，尚无完整训练/权重；详见 [Motto 源码核查](motto-code.md)。不能把论文“空间 token＋重新关注＋框解码”重新命名后当原创，也不能把粗网格编号当精确对象身份。

**对项目的解释：**当前真正需要补充的是三传感器证据如何属于同一实体、同类多个实例如何在关系决策中保持分离。Motto 的网格先验与公开代码的空间解码器提供实现参考，但不直接解决毫米 Depth 无效、局部红外错位、组合目标范围及本赛单框问题。采用区域回读时还要处理训练的 GT 网格标签与推理生成网格之间的误差传播。

## 3. GroundAnything：必须把 IoU 阈值和权重训练分开

[论文 v2，61 页](https://arxiv.org/abs/2609.39600)、[代码](https://github.com/groundingpi/GroundAnything)。它用分块掩码去噪训练并行框/点输出，并保留因果训练；强化学习的 rollout 和概率计算仍是因果策略。DLM 与 AR 版本既有额外转换训练差异，也有学习率、可训练模块、KL、归一化的差异。

更重要的是，Table 19 的 RefCOCOg val/test 汇总 F1 为 DLM 91.61/91.10、AR 84.37/83.56，**但 F1@0.50 为 AR 94.11/93.75、DLM 92.66/92.78**。Table 20 的三个家族数据集在 0.50 阈值也均为 AR 更高。汇总优势主要伴随 0.95 阈值的差异，不能替本赛 ACC@0.5 作结论。没有找到同一最终权重在 REC 上切换两模式的受控表。

**对项目的解释：**空间变量联合训练值得研究；换扩散推理本身不是当前最有证据的提分主线。现役 `qwen3_5` 混合注意力不能只改一个四维 mask 就得到论文模型。论文的精确自推测验证只保持转换后因果分支的输出，不保证保持独立 AR 模型输出。具体源码、版本差异与 LocateAnything 辅助整框训练证据见[并行解码审计](parallel-decoding-code.md)。

## 4. VGent：有监督的候选解码不等于我们以前的冻结编号选择

[论文及附录，14 页](https://arxiv.org/abs/2512.11099)、[CVPR 正文](https://openaccess.thecvf.com/content/CVPR2026/papers/Kang_VGent_Visual_Grounding_via_Modular_Design_for_Disentangling_Reasoning_and_CVPR_2026_paper.pdf)。它将增强后的 MLLM 冻结，另训练与语言层对齐的解码器，选择 UPN/GLEE/SAM 候选；主要收益来自多目标任务。其框标签与掩码标签分开，说明一个框可以在分割覆盖中有用，却不满足单实例框匹配。论文附录也单列候选 oracle，未把它当最终成绩。

公开作者主页只给论文，未找到可确认的官方方法代码；搜索中的同名长视频 Vgent 仓库不是此工作。不能声称已审读不存在的实现。

**对项目的解释：**此前冻结 C 选 ID 失败不构成对所有可训练解码器的否定；但 VGent 仍将最终输出限制在检测器提议中，主要实验还需要大规模密集监督。它不足以支持我们再把已退役的候选流程升成默认主线。可以借用的反而是“身份与范围监督必须分清”，而非其外部候选依赖。

## 5. SLR：同一混合架构上的联合监督证据与反例

[论文 v1，21 页](https://arxiv.org/abs/2610.09418)，正文、实验、附录和配置均已读。任务是手指指向的目标定位：Qwen3.5-4B 先生成一个连续几何状态，再生成四个目标视觉状态，最后仍自回归输出框。前一个位置的完整隐藏向量作为下一个输入 embedding；训练和推理都使用模型预测状态，GT 手指位置/方向和目标区域特征仅作损失目标。视觉塔与投影冻结，语言侧全参数训练；不是只训一个头，也不是当前 27B LoRA 已复现。视觉状态按网格奇偶分组平均，保留四份摘要但仍丢失组内结构，不能据此称其已解决多实例分离。

Table 4 给出重要的正反证据：同为 Qwen3.5-4B，标准集 SFT 的 P@0.5 为 83.9%，联合监督为 87.8%；相似物体子集 SFT/只几何/只视觉/联合的 mIoU 分别为 36.1/28.6/36.9/42.1。**单独几何会退步，但不排除完整模型有益。** 然而复杂子集只视觉 59.7，又高于联合 55.1，不能把加几何普遍化。其 YouRefIt 与文献比较混有 Accuracy/Precision/mAP，作者也承认协议不同；不拿摘要的“领先 5.2 点”作同口径结论。

附录配方为冻结视觉、语言全参、4 H100、四轮、有效 batch12；只列一个种子，未给不确定区间。当前检索未找到可核对的公开方法仓库；论文称将发布代码，附录所称 source package 不等于我们已取得并审读。缓存关闭的评估及包含诊断开销的计时也不能证明部署更快。

**对项目的解释：**它在 Qwen3.5 上给出连续状态反馈可训练的论文证据，降低“混合注意力完全不能做中间状态”的疑虑；但输入 embedding 的循环与本方案一次中层回注不同，不能充当后者源码兼容证明。真正可借鉴的是几何与对象视觉内容的联合约束，以及训练和推理均使用预测状态；不照搬手指射线、五状态、奇偶池化或其训练器。完整系统应直接进入对照，不能用孤立几何头失败提前否定它。

## 6. 综合判断

文献共有的有效变化是：空间位置必须和对象内容一起进入模型的学习目标，不能靠加模块名称；中间空间状态要在最终目标选择发生前被消费；最终框是几何联合对象，不只是四个无关标量。它们也共同暴露一个代价：新空间接口往往需要大量真实框/区域监督，少量新增辅助题不能独自承担从零定位训练。

对本项目，研究重心因此应转到**原生视觉网格中的多实例区域关系记忆**。这是针对历史错误和传感条件提出的组合机制，不宣称发明了空间 token、交叉注意力、区域回读或框头。最关键的对照应直接删去完整模型中的关系更新/回注，而不是要求一个弱线性框头先胜出才允许研究完整结构。
