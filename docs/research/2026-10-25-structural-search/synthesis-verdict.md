# 结构路线独立裁决：让有监督的实例关系状态参与第一次出框

2026-10-25。本文依据本轮历史取证、论文与源码审读作研究裁决；没有新模型实现、GPU 训练或提分结果。遵循 experimental-design 技能。赛题事实以本地官方材料为准；本轮重新读取了已抽取的赛题及提交材料。最终目标是三图与完整 Query 对应的唯一 RGB 归一化框，评价 ACC@0.5，不能用候选覆盖、分割 IoU 或多框严格阈值 F1 替代。

## 1. 裁决

**主线选择：第一次预测之前，在现役 Qwen 主体内部建立有区域位置、视觉内容和传感证据监督的软实例记忆；将完整 Query 的目标、参照与竞争集合绑定到这份记忆，在实例之间计算关系，再将更新后的证据回注语言主体，最终直接读出目标范围。**

这不是“再做一个连续框头”，也不应以增加传感输入、把两次推理改成一次、把 8B 换成 27B 作为创新解释。要检验的是一个确定的因果主张：**最终框监督能训练第一次目标绑定；中间实体有内容且身份不混；真实关系证据能通过这个绑定改变最后选中的对象。**

愿意把原生网格上的单框空间读出作为这条主线的完整输出端，但不把“四数并行”“连续”本身列为提准依据。原生 AR（自回归）输出必须作为同一套中间状态的强对照。若状态机制只在 AR 出口奏效，应采用该出口，保留机制结论，而不是为维护新头放弃有效方法。

**机制不同的备选只留一条：不改推理计算图，在原生 AR 训练中加入框级联合辅助监督。** 它问的是更好的训练目标能否修正已有表征，不构建实例关系记忆，不插入中间证据，也不复活退役 LocateAnything 专家。其依据与限制见第 7 节。

## 2. 必须承认的旧事实与文献边界

源码直接证实，旧 `tools/grounding_structure.py` 已有：三角色参数、目标及最多两个参照的区域注意力监督、同图目标竞争 CE、数值 Depth、视觉出口残差、连续几何头。`ModalStructure.forward` 的查询由 `roles + context(context.detach()) + proposal(A)` 构造，`GeometryHead` 又 detach context 和视觉出口；它们服务于给定 A 后的二次修正。因此，“目标/参照槽”“角色监督”“竞争监督”“连续框”都不能再被描述为未尝试的结构创新。[历史与现役证据](history-and-current.md)、[旧源码](../../../tools/grounding_structure.py)

本轮文献则已经覆盖下列部分：

- ReferFlow：对象索引连续区域状态、区域视觉内容与空间辅助监督、后续定位使用这些状态。它是最直接的“中间状态必须有视觉/空间内容”依据；不能把其机制重新命名为原创，也不能把其多步骤数据与当前比赛默认等同。当前公开信息没有完整方法实现可供复现。[论文](https://arxiv.org/abs/2610.20352)
- Motto：原生视觉网格读取、空间锚 token、视觉回看再进入语言状态以及 DETR 式连续框解码已存在。公开源码没有完整训练损失/训练器，且演示入口存在模块名不一致；它提供结构证据，不是可直接运行的全套训练基线。[论文](https://arxiv.org/abs/2607.24407)、[本轮源码审读](motto-code.md)
- SELF1E：高细节原生视觉特征与语言状态的空间读出已经存在；其注意力修改会损害部分语言/视觉问答能力，且当前 Qwen 是混合线性/全注意力，不能照搬四维掩码。[审读](native-grounding.md)
- SD-VLM、SR-3D、GR3D 等分别提供同格点深度编码、区域表征、区域再输入等局部依据；预给区域的空间问答、估计深度与有内参三维框，均不是当前三传感自由定位的直接验证。[审读](geometry-reasoning.md)
- GroundAnything/LocateAnything 的并行解码不能证明 ACC@0.5 提升；联合监督可能有价值，但速度、严格 IoU 精度、当前单框命中率是不同目标。[审读](parallel-decoding-code.md)

所以，本项目可提出的创新假设是这些部件的一种**明确任务化连接**：三传感证据与实例身份共同保留，完整 Query 的集合/参照绑定在首次框之前发生，成对关系有可追踪的梯度通道，最终范围不受预生成硬框限制。尚无证据支持“全球首次”或“必然超过 .8012”。

## 3. 完整计算图：先决定谁，再决定范围，但两者联合训练

```text
RGB、IR、Depth + 完整 Query + 若干证据位置 + 最后一个 [LOC]
                 │
     原生 Qwen 视觉塔 + 语言前半段（因果掩码不改）
                 │                         │
       完整 Query 条件的证据状态        merge 前三图网格
                 └────────┬────────────────┘
                          ▼
              软实例区域记忆 {a_j(i), v_j, d_j, ir_j}
                          │
         Query 角色/短语 ↔ 实例集合的软绑定 p(r,j)
                          │
             实例—实例关系消息 + 集合内次序信息
                          │
            更新的实例/角色证据回写证据位置
                          │
          原语言后半段 → [LOC]（可看全部证据位置）
                          │
        [LOC] + 全图细网格 + 最终目标相关图
                          ▼
           一个共享单框读出模块 → 唯一 RGB 框
```

### 3.1 不改变现役感知底座的身份

采用公开 Qwen3.6-27B 基座的 `qwen3_5` 架构及完整三图输入；新结构与公平对照使用同一排除重叠后的合法任务混合建立共享训练起点。语言宽 5120、64 层，视觉宽 1152、merge2、DeepStack 索引为空；因此用一处语言层边界的显式状态回写，而非套用旧四出口接口。初版可在约中段选择一处层边界，这是实施起点，不是论文证明的最佳层。保留图像在前、完整 Query 在后、证据位置及 `[LOC]` 最后的顺序。

取 merge 前网格要复用 patch 重排的逆映射，并将三图几何恢复到 RGB 坐标；训练与推理用同一映射。完整 Query 与当前图像在前向始终可见，角色解析不是会永久裁掉文本的前置硬门。语言主权重冻结、LoRA 可训练，视觉塔先冻结；**不能 `no_grad` 包住整个语言前向，也不能在构造 Query 条件状态时 detach**。不改变原生线性注意力的状态传播与全注意力掩码。

### 3.2 角色可变，角色内实例不能被提前平均

“目标、参照、上下文”三个固定向量不够。`the third person from the left next to the car` 至少涉及“人”的竞争集合、序数限定与“车”的参照；更长 Query 还会涉及两个参照、部件或组合。若把所有人的像素先平均成一个向量，空间均值无法恢复第三个人。

实施上区分两层：

1. **实例记忆**：若干可学习证据位置对全图网格做竞争式软注意，得到每个实例自己的区域分布 `a_j(i)`，加空实例状态。使用有限容量，例如初版 32 个记忆位置，是计算上限而不是“图里恰好有 32 个物体”；活跃实例数由存在性学习。它是内部可微的候选表征，不能声称“完全没有候选”，但没有外部 DINO 类别池、没有硬候选框筛选、没有把最终答案限制在候选列表内。
2. **Query 角色绑定**：每个实体短语及其关系状态对实例记忆给出一个分布 `p(r,j)`，一个角色可以同时指向多个人。用小型可训练 span/role 读出表示短语范围与角色，未用角色有空状态；保留完整 Query 状态参与所有后续更新，不用硬解析结果裁图。角色容量与活跃数分开，不能固定为一目标加两个参照。

只增加槽数仍会塌缩。训练必须用真实多实例区域标注做集合匹配，让不同实例对应不同区域/内容；角色与实例的对应另用可得的实体标注监督。训练时做匹配，不向前向网络塞 GT 实例坐标。没有实例标注的样本，不伪造全场景实例清单。

对每个实例保留归一化区域分布、二维位置/范围、一个小空间布局的视觉摘要、有效 Depth 分布和 IR 内容，**不是只保留全区域平均向量**。区域内容重建可以采用冻结原生视觉塔的 GT 区域 4×4 特征作训练目标；这是区域内视觉布局监督，不能称像素级掩码。目标特征可 stop-gradient，预测状态与读图链不能 stop-gradient。

### 3.3 成对关系要真的参与选择

实例 `j,k` 的交互输入包含二维相对位置、范围关系、各自区域特征、有效深度分布的顺序概率及有效率。Query 关系状态调节这些消息，更新目标与参照的绑定分布。可以用一个小型两层关系注意力模块实现，不先展开全图每对高分辨率 patch 的平方级注意力。

对左右/上下一类关系，可使用归一化像素差；对前后/近远，仅在有效深度支持时提供 `P(D_j < D_k)` 等分布比较特征，缺值则该数值证据项为零并保留有效性。深度总体不一定等于主体深度：区域权重由身份学习，既不能用整个 GT 矩形平均作为主体真值，也不能用包含背景的区域均值硬作裁决。无相机内参时不构造伪米制 XYZ，不宣称三维欧氏距离。

序数在**实例集合**上计算。一个可微次序特征为 `rank_j = 1 + Σ(k≠j) p(group,k)·sigmoid((x_j-x_k)/τ)`，再由 Query 的序数条件与内容特征共同更新目标分布。它按实例计数，不按像素面积计数；重复实例槽会使计数失真，所以多实例区域监督与空槽监督是该机制的组成，不是额外美化。公式是提供次序线索，不是把所有关系硬编码为规则。附着、动作、组合等仍依赖视觉内容与后续语言层。

关系更新后的每个实例/角色证据都回写相应语言证据位置；最后 `[LOC]` 在后半段可读取它们。小关系模块可以双向交互实例状态，原语言层继续维持因果顺序，不需为 Qwen 全体 token 定义新的注意力协议。

### 3.4 唯一框的直接范围读出

最终 `[LOC]`、目标相关图与细网格共同驱动一个**共享单框空间读出**。四个边界查询读取同一目标条件的网格，并在小模块内交互；输出按有序区间参数化成合法 `[x1,y1,x2,y2]`，以整框损失联合训练。不是末态向量接四个互不关联 MLP，也不是对预测 mask 求外接矩形。

最终目标图和范围读出仍可访问全部网格，允许超出任一实例区域、跨多个实例、或缩到实例内部部件；内部实例记忆负责关系证据，不能变成答案空间的硬上限。整个输出是一个框，不引入 300 个最终框、NMS 或自由裁判择优。

要严格区分两个“联合”：共享目标状态、边界交互与整框 IoU 反传，是联合几何优化；它不等于显式建模完整四维坐标概率，也不保证永远不混两个相似实例。若用四个独立离散边界分布，不能仅因同时前向就称“联合”。初版宜用共享交互后的有序连续区间读出，避免把四个多峰分布的均值误当实际对象。

## 4. 损失如何改变第一次决定

总目标可写为：

`L = L_final_box + λ_ar L_AR + λ_region L_region + λ_content L_content + λ_role L_role + λ_relation L_relation`。

这不是要求每条样本都有六类标签。每项仅在对应真值确实存在时计算，首轮先确定合理量级，不做庞大自动配权系统。

| 损失 | 真值与作用 | 梯度必须走到哪里 |
| --- | --- | --- |
| 最终框 L1 + GIoU | 官方形式的目标 bbox；这是主任务 | 单框读出 → 后半语言 LoRA → 回注/关系/绑定 → 前半 LoRA |
| 原生坐标语言 CE | 同一目标框序列；保留生成语义与另一输出对照 | 同一语言 LoRA；不是两出口测试择优 |
| 区域/实例匹配 | 有真实实例 mask 时监督区域；仅有 bbox 时用范围/投影等弱监督，不能叫 mask | 实例分离、区域读取、Query 条件；避免多槽指同物体 |
| 区域视觉内容重建 | GT 区域的冻结视觉特征小网格 | 区域状态及其视觉读取；GT 特征只作损失目标 |
| 角色—实例绑定 | 有实体与参照区域标注的关系样本 | 角色读出、实例分布；目标/参照不要互换 |
| 关系/集合监督 | 可由可信多实例标注生成的左右、次序；真实有效 Depth 支持的近远 | 成对关系及其绑定；不从未知深度生成假精确距离 |

决定性要求是 **最终框损失确实反传回首次 Query 条件绑定**。辅助损失只让状态可解释，而没有这条通路，仍可能成为“辅助任务做得不错、最终答案完全不使用”的旧问题。反过来，只有末端框损失而没有区域内容约束，状态可以塌缩为全局语义捷径；ReferFlow 对无监督 latent 的弱收益正提示了这个问题。

训练和推理都从模型预测的软区域读取内容。GT 区域只出现在损失目标，不拿 GT crop embedding 作为训练时回注输入，否则会引入类似先知道目标再学推理的分布差。无需先用错误的预测框硬裁图，区域错了仍能通过全图梯度改正。

## 5. 可实施的数据路线，不把 157 图当成整个资源边界

官方允许外部公开训练数据；现有 226 对/157 图只是当前专项池，适合诊断和末段适配，不是结构从零训练的数据总预算。

第一阶段准备**多实例与语言角色**。RefCOCO/+/g 配合其源 COCO 实例标注提供同图实例及目标 Query；对场景里真实共存实例构造左右、序数、部件/整体范围对照。只能依据已知标注生成关系，不能从一个目标 bbox 推断整幅图的全部实例。Visual Genome/GQA 等有实体关系标注的数据可以补参照关系，真实清洗与映射量尚未审计；不应在计划中写成已整理完成。部分部件数据可补目标范围，不能让“完整物体”变成唯一先验。

第二阶段补**有效传感证据**。SUN RGB-D/SUNRefer 一类数据可以提供真实 RGB-D 与多物体结构，但其 3D amodal 框不能直接投影后当本赛可见 2D 范围真值；需用可靠 2D 实例/区域标注，或只训练可验证的几何辅助任务。现有合法 RGBT、RGBDT 与 RoboRefIt 来源负责域适配与最终框；IR/Depth 缺失来源保留缺失标记，不能用 RGB 复制出假三图监督。跨序列/场景做分组留出，不能按同图不同 Query 随机分组。

第三阶段从共享训练起点联合适配：历史审计已确认 Arm2 混合中有 508 行引用与官方测试帧重叠，因此 Arm2 冻结作历史成绩参考，不默认继承其权重。新结构与公平对照从同一公开 Qwen3.6-27B 基座、同一排除重叠后的合法任务混合建立共享起点，再加入前两阶段的有监督实例关系样本做等数据续训，训练语言 LoRA 与小模块；最终用比赛风格框及同图难例混合。区域模块可先在冻结/缓存视觉特征上预热，随后联合训练是必须的；预热不是“线性头先提分，才许做关系模型”的准入测试。

具体外部图数和训练步数要根据可取得标注、算力确定；本轮没有完成下载/清洗和资源报价。论文十万至百万级训练说明不能期待 157 图覆盖所有新能力，但也不意味着必须原样复制 32 张 A800 的全流程。利用公开基座的语义能力、只训练小空间模块与 LoRA，是可做的研究切口。需把“额外数据收益”与“结构收益”用同数据对照分开。

## 6. 直接比较完整模型，最强反例优先

不接受 G0→G1→G2 每步必须先胜才能允许完整结构的串行门槛。一个单独末层头失败，不足以否定有内容监督和主体反馈的完整系统。第一轮应直接运行完整模型与少量能回答机制问题的配对比较：

- 同数据/图尺寸/共享初始化/训练预算的原生 AR：解决是否超出合法共享起点的普通续训及新增数据收益；Arm2 不充当该配对对照的初始化。
- 完整模型删关系更新：保留区域状态、内容监督、回注和同一出口，检验实例关系计算是否真的有增量。
- 完整模型删主体回注：保留同容量的区域/关系模块和最终网格读出，检验是内部推理改变，还是一个旁路定位器独自完成任务。
- 完整状态接 AR 出口：尽量共享状态训练与辅助目标，检验新空间头是否必要。若两出口训练成本不同，报出差异，不声称完美单变量。

不是必须同时铺满 RGB、IR、Depth、各层、各容量的组合表。先回答主因果，再定位传感贡献。

**最强反例 1：已有 27B 能表示关系，问题主要是训练分布和标签。** 若同样增加实例/关系数据的原生 AR 获得同等改善，或删关系模型一样好，则结构主张不成立；不能把数据收益归给关系模块。

**最强反例 2：模型绕开中间状态。** 对同图两名/多个相似实例交换区域内容，保留位置；或交换深度关系、保留 RGB。若角色/关系问题的最终目标完全不响应，而简单末端图读出仍能解释所有成绩，则“中间证据驱动首次推理”失败。干预造成变化本身只说明依赖，不能说明有益；最终仍要看正确框净增。

**最强反例 3：状态拆分错了，关系越强越自信地选错。** 序数题尤其敏感：漏实例或重复槽改变排名，参照绑定错误会连锁污染目标。需要记录实例分离/角色绑定与最终错误的对应。如果完整模型只改善已给明确参照的简单样本，却损害自由 Query，不能靠更多硬规则保持路线。

**最强反例 4：新框头解决边界、破坏身份。** 若中间目标与 AR 出口命中、空间头错，而四边界更紧只提高高阈值 IoU、不提高 ACC@0.5，则保留状态机制并回到 AR 出口。GroundAnything 的阈值差异已经说明，紧框与 .5 命中不能互代。

最终主要报告独立场景逐题 ACC@0.5、救回/损害、错实例/范围错误，以及关系/序数/有效传感子集。反复使用的 City 新版 400 是开发集；27 条改过 Query 必须重新推理，不能用旧结果拼接。主线未运行前不得宣布优于现役官方 .8012。

## 7. 唯一备选：训练时的框级辅助目标，部署仍原生 AR

若主线的实例分解和回注成本过大，备选不是恢复冻结检测专家，而是保持现役输入/推理路径，训练时让 Query 后的共享状态同时承担单框 L1/GIoU 或框边界对齐预测，部署仍输出原生 AR 框。空间监督直接回到语言 LoRA；辅助头训练后可移除。它测试的是“逐坐标语言 CE 缺少整框几何代价”，而非“第一次目标选择缺少可用的实例关系记忆”。

LocateAnything 的同数据 NTP+块监督、仍用 Slow 输出优于纯 NTP 的结果支持研究训练目标，但这是多框 F1，不能直接预测本赛。当前混合注意力不适合先大改成 PBD/DLM，因此最小备选优先使用共享状态上的可微单框辅助头，不把 token argmax 后的 IoU 冒充可微损失。不需要候选 ID、外部裁判或新的测试时投票。

备选也不是技术新颖性主张；它与旧连续头的关键不同在于**训练时辅助损失是否进入现役第一次 AR 决策的 LoRA，且推理接口完全不变**。需要和相同总更新量的普通续训直接比较。若只改善辅助头、不改善最终 AR ACC，就结束该备选，不继续堆输出规则。

## 8. 当前接手结论

可进入实现的主方案已经确定为一个完整计算图，而不是候选论文清单：可变角色—实例集合、真实内容/区域监督、成对关系、一次中层证据回注、全图单框读出。优先复用现役视觉塔与 LoRA 训练流程，新增小空间模块及自定义 HF 前向入口；标准 vLLM LoRA 请求无法自动表达中层回写，需要对应推理入口。

本轮没有实施或训练。下一步工作是把外部实例/关系标注映射、现役网格坐标映射与完整模型接口一起做成最小可训练版本，随完整模型安排删关系、删回注、AR 出口三个关键比较。无需重新讨论已经退役的专家，也无需等待简单四数头先证明收益。
