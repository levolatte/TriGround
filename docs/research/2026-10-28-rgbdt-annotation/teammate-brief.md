# 半决赛数据标注速查

完整背景、来源和例子见[《半决赛训练数据与标注指南》](city-semifinal.md)。

## 数量与分工

建设能够接替City的主训练集：**3600题、约700图；另建约400题、80–100图的开发集。** 以RGBDT500为主，其他公开训练数据补齐素材。训练和开发按序列或实际地点分开。



| 内容            | 占比  | 全量目标 | 300题试标 |
| ------------- | ---:| ----:| ------:|
| 基础对象、外观、动作和位置 | 35% | 1260 | 105    |
| 同类竞争与排序       | 25% | 900  | 75     |
| 参照关系及关系组合     | 15% | 540  | 45     |
| 整物、部件、组合和区域范围 | 15% | 540  | 45     |
| 可靠距离、红外和弱光互补  | 10% | 360  | 30     |

平均每图约5题，丰富场景可做4–6题，简单图少做。每题优先换真实目标、部件或决定答案的关系。距离/红外素材不足时，转补可靠的实例、参照和范围题。

## 每题操作

1. **领图。** 使用已排除官方测试重叠的公开训练素材，保留序列/场景组身份。
2. **定目标。** 确定完整对象、部件、组合或区域。排序题先确定候选集合、方向和序位，参照题先找清参照物。
3. **写英文。** 简短自然、唯一指代，保留已经核实的排序和关系。身体侧与画面侧、离相机与离物体分别写清。
4. **画RGB框。** 紧致包含目标全部可见部分，遮挡不外推，出画停边界。部件和组合重新画框。先存像素坐标，再除以本图实际宽高。
5. **记证据。** 记录实际模态及Depth类型。距离依据落在主体有效小块；显示亮度未经来源确认不解释成距离或温度。辅助模态无效但RGB可答的题可保留并注明。
6. **盲复核。** 另一人先只看原图与Query独立定位，再比目标、单位、唯一性、边界及模态依据。有分歧就修订或裁决。
7. **汇总。** 每题一行JSONL，保存来源、图像尺寸与路径、Query、目标类别/单位、像素框/归一化框、必要参照、制作人和复核状态。每批分别统计题数、图数、场景组数及实际配比。

## 容易混淆的范围

| 描述                                                  | 框什么                       |
| --------------------------------------------------- | ------------------------- |
| umbrella canopy（伞面）                                 | 只框伞布                      |
| rider（骑手）                                           | 只框可见的人                    |
| rider together with the bicycle（骑手及自行车）             | 人和车共同外接框                  |
| second bicycle in the row beside the wall（墙边那排第二辆车） | 在指定那排内排序后选单辆车，Query写清计数方向 |
| reflection of a post（木桩倒影）                          | 框倒影，不框木桩                  |

保留原参考框和简短修订原因，同图关联标签同步修正。复核解释和答案只存元数据，不放进定位输入。三模态与两模态来源分别统计，缺失模态不补造。
