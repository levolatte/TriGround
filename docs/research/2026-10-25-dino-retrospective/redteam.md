# 独立反方审查：新定位架构应撤回哪些承诺

2026-10-25。依据本地旧实验记录、实际候选构造源码以及本日新提案，审查架构依赖，不评判尚未运行的新模型成绩。本次没有模型训练、推理或新的论文复现。历史 C 不是本日27B新模型，历史412题也不是新方案的独立评价集；旧结果用于反驳推理跳跃，不能直接预测新模型分数。

## 裁决：撤回默认整体替换，保留为竞争研究

**撤回“以DINO空间分支接管最终出框，首轮优先完整实现C”的主线地位。** 新结构并非简单重演旧候选选择器，但目前的胜负论证仍依赖同一个未经证明的分工：检测器负责可靠的对象与空间，Qwen负责提供正确语义，两者连起来就能保住原有能力并增加定位精度。历史结果恰好说明，这种分工不能靠模块名和接口正确性成立。

这不是宣布新结构必败，也不是要求先跑十几个零碎辅助任务。应把它改写为一个完整的竞争假设：“通过重新训练，将27B的条件特征迁移给三模态定位器，可能学到优于直接框生成的预测器。”它需要和保留现有视觉决策路径的结构平等竞争，不能先宣布它已经“保留27B视觉理解”。

保留原始Depth、二维空间特征、可微框监督和明确坐标系这四个研究方向。撤回的是特定的**能力归属及替换优先级**，不是否定这些方向。

最关键的源码事实是 `aux_selection_evidence.py::merge_candidate_boxes` 首先把C框原样放入目标池，随后才合并检测；候选截断仍优先保留它。**339是C与外部候选的联合上限，不是独立定位分支的成绩或上限。** 报告中的RGB原框238和IR原框96也仅针对该构造中保留提议的来源，不可把它们冒充独立DINO全量评价。需要主审计的来源拆分才能量化互补性。

对新架构最致命的旧教训不是“DINO这个名字不能再出现”，而是：**为已有强预测器新增一条决策路径，既要增加可得正确答案，也要学会不破坏原来正确的答案。** 端到端训练改变了学习机制，但不自动满足这两项条件。

10月1日[停止复盘](../../../experiments/evidence_decision/POSTMORTEM_20261001.md)还明确否定了“尚未训练，所以继续投入”的管理逻辑：113条合格教师终局全是ID选择，自主框终局为0，数据总行数并未覆盖声称要补的能力。新方案不能把同一辩护改成“框可移动，训了就能逃出检测先验”。要继续研究，必须指出真正改变哪个失败依赖，以及什么现有监督能教会它；不能靠未来训练可能成功来维持当前主线地位。

## 1. 900个动态槽不是任意目标表示能力

新方案的槽可逐层移动，最终框不是从旧JSON候选中拣一个；因此339和73都不是新模型的数学上限。这个区别应保留，不应歪曲。

但是，初始锚框仍来自原图文路径的top-k，选择离散且detach；Qwen在decoder中才进入。高层语义不能在本次前向中直接改变最初哪些空间位置入选。decoder可以移动框、访问空间特征，故也不能反过来声称“未入top-k就永远不可能命中”。真正未解的是：训练能否让有限槽在需要时离开熟悉的整物体锚框，形成部件、表面、组合区域、边缘和非典型对象。

“没有固定候选硬上限”只是一条表示支持集声明，不是学习成功证据。900是初始化配置，不是900个语义完备的实例。槽数多也可能只是同一显著对象的多个重复框。新文档应把“对象槽”改为“可学习定位槽”，除非证明其中确实形成可供参照与序数推理的对象集合。

**处理：** 保留动态连续框；删除“动态槽已经解决候选瓶颈”的暗示；DINO只作为一种初始化。若空间分支对原模型正确的稀有目标/部件丢失严重，应更换区域表示或初始化，不能用增加槽数、再加关系头维持原架构。

## 2. 读取27B隐状态，不等于保留27B视觉能力

新接口有三项同时改变：Qwen只读较低细节RGB，IR/Depth退出其视觉决策；只执行输入前向，不沿用原有输出生成过程；把Query末层状态投影后交给另一套定位器解释。接口文档证明张量可取、维度可接、LoRA可受梯度，**没有证明这些状态已经包含可被新头稳定读出的目标身份和范围。**

所有Query token优于简单均值是合理设计动机，却不是无损性证明。5120→256也不能仅凭数字判死刑；任务充分统计量可能很小。真正要反证的是：维持输入信息时，新接口能否读出原模型已经会做的决定；降低细节后，决定所需的属性、小部件和序数集合是否还可见。因果注意力允许Query读前面的图像，只说明信息可达，不说明输入前向等价于经过后续生成得到的答案。

新训练从公开基座而非现役Arm2开始，也意味着“保留现役能力”不能仅靠保持同一个27B名称来保证。公开基座能力、现役微调能力和新桥接后能力是三种不同对象。

此外，两个分支是信息不对称的：空间decoder看IR/Depth，27B不看。可以由decoder完成传感器相关的目标推理，但这时不应说这些判断由27B的视觉推理完成。27B若在低细节RGB中已误判身份，桥接后的小定位器必须学会纠正它；这恰是新能力，不是免费继承。

**处理：** 将“保留27B视觉理解”统一改成“尝试迁移27B的图文条件表示”。不默认压低Qwen输入细节；在同等视觉输入下先进行完整结构比较，否则能力损失与接口失败混在一起。当前证据不足以把低细节语义支路写成主方案优势。

## 3. 一张计算图不等于两个预训练系统有效合作

新方案的框损失确实可以回传至桥与语言LoRA；这与冻结C的旧外挂有实质区别。旧错误不能被当作联合训练必败的证据。

但梯度只说明损失能够改变参数，不说明它教会了所需分工。保留BERT并把Qwen残差初始化到接近零，利于不立即冲坏定位初始化，也允许网络长期忽略Qwen。反过来强行依赖Qwen，又可能让定位预训练接口失配。“加了27B”和“27B有益地改变了最终定位”仍是不同命题。

只有一个目标框时，按匹配槽计算CE和框损失能教最终目标选择；它没有要求其余槽完整枚举物体、辨识真实参照物或保存序数集合。即使没有把其余槽标成背景，**没有负标签也不等于有保护对象集合的正监督。** 几个重叠槽可轮流成为匹配赢家，槽排他并不等于真实实例辨析。

公开对象监督可以缓解这个缺口，但现稿尚没有本项目可用训练清单和与目标错误匹配的覆盖证据。RGB指代数据、RGBT数据与少量三模态数据覆盖的是不同联合分布；把它们写在同一清单，不能证明网络学到了“真实Depth＋罕见部件＋复杂指代”的组合。

**处理：** 保留可训练桥作为可检验假设；不把端到端当作正面性能证据。保留D（去桥重训）为必要裁决：若D不差，删除昂贵桥，不再以更复杂桥“保住大模型主线”。同时检查完整结构是否损害原模型正确的目标类型，不能只看平均候选覆盖。

## 4. 三模态空间路径值得保留，但它没有得到历史背书

旧IR提议对C错题无独有覆盖，否定的是当时IR检测候选的可见贡献，不是热红外本身。新方案在图像特征层融合、直接使用有效数值Depth，确实不同于把候选掩码统计写入文字提示。

其未经证明的部分同样明确：数值Depth如何绑定到所指主体；局部IR特征是否对应RGB同一对象；模型是否只是识别数据来源；辅助模态是否真正改变最终目标而非仅影响无用特征。单一目标框并不直接提供这些对应监督。

**处理：** 保留原始数值、valid和空间对齐方向；不将它们绑定到DINO唯一输出头。正确模态、缺失模态及配对错误模态的干预可作诊断，最终仍须靠同数据重训与独立场景结果确认有益使用。旧43道近远子集选择多对1题不能当Depth因果证据。

## 5. 主动观察不能靠换名字复活旧Agent

新提案将动作轨迹纳入训练、最终输出全局框，区别于旧冻结选择和局部坐标协议，理论上避开了一部分旧错。保留该研究方向可以，但不能因主方案受到质疑就直接升格它。

同一份新文档末尾提到未来模型组合与选择器。旧实验对它的约束最直接：**互补答案集合只给出上限，选择器需要自己的学习与独立评价。** 不允许先把多个新模型拼起来，再假设Qwen会挑对。训练集交叉预测可提供选择监督，但其实际训练分布必须包含模型真实冲突、原答案正确的保留和池外情况；没有这些结果前，不承诺组合收益。

**处理：** 不恢复未训练工具决策，不把提示修补当作策略训练。若研究主动观察，只比较训练过的完整策略和等信息/等预算直接推理，明确区分新证据、额外算力及动作学习贡献。

## 改写后的研究主线

在新研究尚无结果时，原有可复现直接框预测器继续承担成绩基线。研究问题从“谁负责语义、谁负责空间”改为：**怎样在保住已有目标识别能力的同时，让高细节与传感器证据直接影响最终框？** 不先把答案限制为检测槽。

值得与DINO方案平等比较的一种不同结构是**以多模态主模型为中心的目标条件定位头**：保留足够细节及现有多图视觉输入，让目标条件状态能读取主模型的视觉空间表示；必要时再读取新增高分辨率/数值传感器特征；直接预测Query所指区域，不先要求它成为预训练检测类别下的对象槽。生成框分支可作为训练期能力保留约束与独立对照，最终输出机制需训练和评价决定，不能用未训练门控选择两条答案。

这里不是推荐一个已经胜出的新模型，也不声称“四维MLP”能够可靠定位。该结构仍要解决空间索引、分辨率、目标条件与框监督的接口；它值得研究的原因是更少地预先剥离已经有效的视觉决策路径，并取消“所有目标首先属于检测对象集合”的依赖。完整架构设计需要后续研究，不能拿这一段替代实现规格。

近期裁决只需抓住三个相互竞争的完整预测器：等数据的直接框强基线；保留多模态视觉决策的目标条件定位结构；本日DINO＋Qwen桥结构。后一结构若要主线地位，必须以最终单框净收益争取，且不能靠额外数据或更大输入掩盖归因。无需为每个论文模块安排单独跑通仪式，也不应在没有目标分布证据时优先同时重建语义桥、IR配准、Depth编码和对象集合。

## 必须修改的原文结论

| 原提案表述/安排 | 本审查要求 |
|---|---|
| “主方案应整体替换” | 撤回；改为完整竞争结构，尚无替换证据 |
| “保留27B场景/视觉理解” | 改为尝试迁移图文条件表示；张量接口核对不是能力保留证明 |
| “900动态槽避免候选瓶颈” | 只承认取消旧固定文件上限；对象性、覆盖与可训练性仍待证明 |
| “对象自注意力承载关系，首轮足够” | 改为表达能力假设；单框监督不保证学习真实集合与参照关系 |
| 首轮默认低细节Qwen＋仅RGB | 删除默认优先级；先保留足够且可比的视觉信息，降细节作为成本取舍另评 |
| 优先完整实现C，随后再决定 | 取消该排他优先级；完整候选结构按证据竞争，不以接口可接为选择依据 |
| 原始Depth、空间特征与框损失 | 保留，允许接入不同主干与输出结构 |
| 数据公平、独立场景、去桥重训和模态干预 | 保留；这些是有效判据，但不能倒过来证明当前选型合理 |

最终结论是：新方案修掉了旧系统的一些明确失败机制，却尚未建立新分工的可靠性。它有资格做实验，没有资格凭“端到端、动态槽、27B语义”三项描述接管主线。
