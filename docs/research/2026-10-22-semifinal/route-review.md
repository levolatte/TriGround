# 半决赛主线裁决：先改变实例判别，再增加系统复杂度

2026-10-23。依据本地赛题全文、接手报告及本轮三份论文/源码研究，使用 experimental-design 技能审查机制与对照。本轮未训练、未运行新模型；文中优先级是决策建议，不是已取得的提分。官方主指标为逐 Query 的 ACC@0.5；现有 0.8012 是历史记录，当前 27B 的错误组成尚未建立。

**修订裁决：针对实例混淆的数据构造＋直接框 SFT 是底座；最小新增机制是同图候选判别辅助目标，不更换骨干。相同行、曝光和独立交叉熵下，成对排列没有新目标，不作为主消融。**

## 单一推荐主线

**以现有原生三图 Qwen 27B 为底座，做“同图竞争实例、成对查询、直接框”的监督微调。** 保留现有普通样本，新增的训练单位必须包含：同一场景中两个容易混淆的真实对象、分别指向它们的有效描述、不同的 RGB 真值框。例如同图两辆相似车，查询改变左右、属性或参照关系，答案随之改变。优先用公开数据的已有真实描述；不能机械替换 left/right 就假定生成了正确反事实。

机制是迫使模型根据查询区分竞争目标，减少对“该图最显眼对象”的依赖；最终仍一次生成四坐标，不要求长思维链，不让检测器限定所有答案。RGBT-GroundBench、已有 RoboRefIt 转换器和原生 ms-swift 管线可复用。近远样本须有可信原始深度及对象关系，不能把伪彩图亮暗当毫米测量。先以现有 3.6 权重做最小训练，3.8 的独立零样本筛选可以同步进行，不让模型升级阻塞数据机制实验。

上述成对查询只改变数据覆盖，不构成结构创新。**普通 SFT 没有显式硬负损失**；相同行与曝光下，把查询排成对并不会改变独立交叉熵目标。真正的最小增量选同图候选判别辅助任务：主任务输入原三图和 Query，输出四坐标；辅任务输入相同三图和 Query，再给两个全图归一化候选框 A/B，输出 `A/B/both/neither`。根据两个候选各自是否 IoU≥0.5 标注，随机候选顺序，包含同类错实例、错误尺度和双失败框；不能把两个合格框强制标成一正一负。

复用现有语言 LoRA 和 ms-swift 多任务 SFT，损失为 `L = L_boxCE + λ L_choiceCE`：各任务先对输出 token 的交叉熵取均值，再加权。模型须在相同查询下辨别正确与错误区域，监督问题因此发生改变；这应称为**判别辅助目标**，不称新骨干或新融合结构。推理仍一次直接生成四坐标，辅助任务只用于训练，不立即增加候选选择流程。辅助分类改善能否迁移到直接框是待验证假设，若只提高判别准确率而最终定位不涨，就不能宣称有效。

几何边界错误作为主线第二阶段：先确认当前 27B 仍有足够“对象正确而框未过线”的题，再增加对应监督或短框奖励。不能仅凭 IoU 在 0.3–0.5 就认定对象正确，相邻实例同样可能重叠；需要在允许使用标签的开发数据中判别身份。也不应只追逐 0.49，阈值附近标注噪声很大，且 0.55 的框退到 0.49 同样扣分。

## 低成本备用与其他方向排序

**备用只做冻结权重的 RGB 高分辨率、IR/D 较低分辨率。** 当前三图全部放大消耗大量视觉 token；先比较“只降辅助模态”和“把节省预算转给 RGB”两个有明确区别的设置。前者是成本/干扰消融，后者才是预算重分配。它可能提高小目标可见性，也可能损伤低光和深度关系题，须看全分母净翻转。若没有增益就保留原三图 2×；不要立即加门控、tiles 和不同提示把原因混在一起。

固定重叠 tiles（局部图块）排在该备用之后。它避免错误预测框决定搜索范围，但仍有跨块截断、实例重复、坐标映射和输入分布变化；“固定”并不保证有效。论文中动态切图的成功不能直接移植到未用切图训练的 Qwen。全图必须保留，且推理时不能用真值选图块。以现有错框为中心继续裁剪最容易重复旧局部细化的失败机制。

Qwen3.8 同结构只降低适配成本，不证明它更会定位，也不证明旧 LoRA 可迁移。零样本应与 **3.6 零样本**同提示、同视觉预算配对，另和 Arm 2 比较实用价值；未超过微调 Arm 2 不能据此否定其微调潜力。若零样本呈现互补，值得一轮相同新数据、相同训练预算的短微调。

Rex-Omni 是独立备选研究，不先成为主线依赖。先以完整原查询直接框推理，再把短语化作为单独消融；若一开始删掉关系词，等于预先删掉赛题。它即使总体弱，也可能提供独有正确框。只有这种互补存在，才投资学习最终框选择；旧基线框保留在候选集合只是必要条件，**不保证选择器不会把正确答案换错**。可先做两个模型间选择，没必要重建完整 Agent。其研究许可证适用性按主报告处理。

GRPO 比 DPO 更直接对应奖励，但两者均排在直接框 SFT 与候选判别辅助目标之后。现有奖励建议的阈值加小连续项合理；同一对象全部过线无需磨框，失败组若仍有 IoU 差异可学习。要求“先有大量跨阈值采样”才准实验过严：先用小规模采样看多样性即可，纯二值全同不能等同完全无学习机会。反之，全部是 IoU=0 的错误实例时，shape 项不能凭空提供语义方向，应回到数据/感知。DPO 对数字串的概率偏好不等于几何偏好，不作为默认省钱替代。

原始深度证据值得保留，但属于明确近远题的专门分支。必须区分“离相机近”和“离另一个对象近”：两个 ROI 深度差不是物体间三维距离，不能泛化处理所有 near。共享对象表、多 Query 联合约束有潜力却排后：对象表漏检会共同限制所有查询，先做每个 Query 的直接预测再共享证据更稳。一对象可对应多个查询，禁止一一匹配；仅有明确语义矛盾才可施加软约束。

## 最大缺失对照与旧路线换皮风险

最缺的是 **当前 27B、同图组、同输入协议的逐题结果**。旧 8B 的 292/412、候选 oracle 339/412 只能说明历史现象，不能推出27B剩余错误仍有47题候选空间。官方无真值时不能生成所谓官方错误谱，更不能人工补标测试集；先在可合法使用的标注集建立当前错误谱，City412只作历史诊断。

主线对照必须区分数据和目标。数据构造收益比较等预算的普通数据与针对实例混淆的数据，承认样本组成发生改变。辅助目标比较**相同图像/Query 池、相同总训练视觉 token 预算**：A 只做直接框 SFT，B 把部分预算分给候选判别；再以相同辅助任务预算比较同类硬负与随机负。第一项测辅助目标是否改善直接框，第二项测是否来自竞争实例辨别。不能把相同行的成对排列与独立排列当作机制消融，也不把“新训练对不训练”当充分对照。

新增数据按场景/序列隔离；反复用过的 City412 不能靠重新随机切分变成独立证据。无需等大型完美验证集，从尚未用过的合法外部图组做小而干净的留出即可。

第二个缺失对照是 **单纯更多计算**。新基座、tiles、候选评分或 GRPO 都应与同预算下当前主线的直接预测/采样机会比较，不能把增加数倍算力的收益全部归给新机制。机制研究需要配平预算；最终争分允许加算力，只需把两种结论分开。

“质量条件路由”若只有亮度阈值就是旧规则融合；“候选正确率评分”若仍是提示大模型自报置信度就是旧选择器；“阈值优化”若只有重采样困难题就是数据配比；“全局加局部”若仍围绕错误框反复追问就是旧 Agent。真正的新变量分别应是可验证的传感质量监督、由真值训练的选择目标、真实跨过阈值的优化信号，以及独立于错误初猜的视觉覆盖。

## 实验先后与止损

1. **立即取得信息**：当前27B在合法标注图组推理，记录选错实例、尺度/边界、不可见/低质量三类；同时跑3.8零样本与冻结权重的非对称分辨率。无需先补齐所有论文消融。
2. **第一轮训练只押主线**：针对实例混淆的数据混入普通样本作为直接框 SFT 底座；以相同图像/Query 池和视觉 token 预算比较纯直接框训练与加入候选判别辅助目标，再比较硬负与随机负。看总 ACC、成对查询同时答对率、正确框被破坏数。若辅助分类改善却直接框不涨，停止该目标；若只在训练源或单类模板改善，先修正语义与来源覆盖。
3. **按失败机制分流**：身份错误下降而几何残留时试短框阈值 GRPO；主模型看不到而 Rex 独有覆盖时试两模型选择；只有深度证据可解释的关系题值得加入数值证据。不要同时开三条大训练。
4. **止损看可纠正的因果失败**：只涨平均IoU、不增加过线题；候选上限几乎不变却不断调选择器；关掉深度后“深度方法”收益不变；裁剪持续毁掉原本正确关系题——这些比“不显著”更有停止价值。少量正向净翻转但区间宽可继续一次合规独立确认，不应以固定显著性门槛封死竞赛尝试。

框决策最大化 P(IoU≥0.5) 在理论上正确，但估计它仍是学习问题；自报置信度、坐标平均、多数相同答案都不是该概率。优先输出证据最强的原始候选框，跨实例绝不平均。当前信息不足以承诺哪条路线带来多少百分点；足以决定以实例混淆数据构造为底座，用候选判别辅助目标检验新的监督机制，并以分辨率备用保留即时收益机会。
