# 半决赛 RGB/红外/深度融合研究：从传感器证据到 RGB 定位框

日期：2026-10-22。只做文献、开源实现与仓库只读研究；未训练、未下载模型权重、未改业务源码。基准以本地 `contest/基于大模型的多模态视觉理解与推理.pdf`（转写 `tmp/takeover_20261022_contest/基于大模型的多模态视觉理解与推理.txt`）为准：输入 RGB、热红外、毫米单位 uint16 深度、英文 Query；输出 **RGB 图坐标系**归一化 xyxy；最终指标是逐 Query 的 IoU≥0.5 命中率。官方称图像已经人工空间对齐，但并不保证每个目标局部没有残差错位、无效深度和红外低对比。测试集只准推理，不准训练或人工改预测。

## 判断

最值得先转化的是 **模态对齐且带 Query 与 RGB 框的训练监督**，尤其同类多实例、低光小目标与可验证的近远关系。当前 Arm 2 ck500、2 倍放大曾记录官方 0.8012，但其训练 City/RoboRefIt 深度曾被 uint16→RGB 截断，后续修正的 Arm 4/5 未超过该分数；这不能证明深度无用，也不能把后续修复归给 Arm 2。仓库 2026-09-27 审计显示早期自定义融合、候选选择与多步工具没有稳定净收益。下述路线只保留 **一次 Query→RGB 框的主决策**，让辅助模态先获得正确监督、度量其质量，再通过受控的局部证据影响该决策。是否需要新结构，要由同一冻结基线上的配对命中翻转决定。

### 论文和实现所揭示的实质机制

1. **RGBT-GroundBench：传感器域差与 Query 先行。** 论文第 8–10 页用共享 CLIP 权重但独立 RGB/TIR LoRA、文字查询视觉块、再按亮度/局部/全局特征融合。源码 `models/mmvg_fusion.py:944-955` 固定 RGB rank 16、IR rank 48，并在 `:1391-1427` 分别运行两路视觉编码、跨路注意力；`models/mmvg_fusion.py:235-345,583-612` 实现文字作 Query 查视觉 token，`models/mmvg_fusion.py:1181-1188,1301-1338,1452-1469` 完成亮度先验、token/通道门控及最终 box 回归。`datasets/data_loader.py:336-367,389-409` 将 RGB/IR 成对加载，IR 只取灰度并拼为第 4 通道；`engine.py:70-110` 调用定位损失。论文表 5 显示 AMA 是最大增量，LAVS 与 TPF 对难例再有小幅增量；表 4 同时存在 MV-OneRef-L 在 RefFLIR test 60.89 < RGB-only 64.60、MV-HiVG-L 在 RefMFAD test 61.31 < RGB-only 63.72，因此论文“所有模型融合都改善”的概括不能当成逐模型定律。论文 TPF 公式与仓库默认 `IAFv3` 也非逐项相同：后者额外使用可学习权重、温度、极端亮度置信度和残差，复用时应以实际源码为准。源码有写死的作者环境预训练路径（`:815-835`），不是可直接挂到 Qwen3.6 的即插即用模块。
   附录第 19–21 页的多模态大模型（MLLM）对照尤其支持逐样本关模态：224² 下 Kimi-K2.5 的 RefMFAD test 从 RGB 19.70 降为 RGB+TIR 9.85；原分辨率下 Qwen3.5-Plus 同集从 56.86 降为 52.76。增大分辨率可显著提高绝对分数，却没有自动解决错误融合。这些模型含在线服务，**只能用作论文诊断证据，不能用商业闭源 API 生成 AIC 测试答案**。
2. **RDTTrack：RGB 锚定，但没有文本和数值深度。** 论文第 5–10 页、附录 A.3：ZED 的 RGB/D 像素同步，独立热相机经人工特征点矩阵映射至 1920×1080；还刻意包含视角不一致、平面物体深度弱、热对比失效等片段。源码 `lib/models/rdtt/vit_ce_prompt.py:75-101,220-260,305-355` 把深度和 IR 经各自 patch token、所谓“正交”混合后作为 RGB 编码层的提示；`lib/train/base_functions.py:111-120` 冻结非提示/融合参数，`lib/train/actors/rdtt.py:86-113` 是焦点、L1、GIoU 追踪损失。论文同结构 RGB+D/T/三模态 AUC .737/.734/.752、去掉融合块 .733，**只证明该追踪设置的收益**。注意源码 `lib/train/dataset/rgbdt.py:13-38` 将深度按每帧中位数截断，再 min-max 映射和 JET 伪彩，毫米绝对值及跨对象深度差不保留；`DepthIR_ort_block` 以逐通道乘积除范数，缺少按通道求内积与平方范数，不是严格的向量正交投影。故其实现既不适合直接读“近 1 米、远 4 米”，也不应机械复制“正交”代码。
3. **Refer-it-in-RGBD：几何和对象关系的两级监督。** 论文第 3–7 页先在 0.05m 三维 voxel 做语言热图，再用热图加权最远点采样、对象投票和 Query 匹配；表 4 的只用 voxel 热图 12.2、只用对象级 28.6、完整 35.9，说明“粗区域/对象身份”是不同误差源。源码 `dataset/sunrefer_dataloader.py:96-121,171-220` 加载三维点与 RGB/语言、产生热图监督，`network/ref_net.py:65-116` 加权采样与投票，`loss/ref_loss.py:118-195` 用 IoU 监督提议得分和框响应。该工作依赖相机标定、点云与 3D 全物体标注；AIC 只要求单张 RGB 可见框，传感器虽对齐却未给外参和完整 3D 物体框，移植网络会换任务。真正适配的是用 2D ROI 内有效深度与同类实例关系做小规模、可证伪的训练监督。
4. **RGBX-R1：论文概念适用边界很窄。** 正文第 3–5 页及补充第 11–13 页：从 VisEvent、DepthTrack、RGBD2022、RGBT234、LasHeR 抽帧，97.24% 样本为两张带目标框模板 + 六张搜索图；Qwen2.5-VL-32B 分 Understand/Associate/Validate 生成教师解释，使用已知 GT 进行自评再人工筛出约 5,000 条。SFT 在解释 token 上给模态频率权重；GRPO 奖励包括视频时距加权 IoU、模态分类+与教师解释 token 匹配、格式。论文自身单 X 与双模态结果证实 X 信号有增益，但没有脱离视频模板的文字指代试验。其深度提示规定**近=暗、远=亮**，而本项目 `tools/prepare_qwen3vl_native_sft.py:28-68,82-87` 的预渲染为**近=亮、远=暗、黑=无效**；复制其提示会把近远颠倒。教师“解释”可能含外观幻觉，不能用无图像依据的 CoT 当成已验证模态依赖。论文没有给可公开运行的训练脚本或成品数据链接；不能写成可复用开源实现。

## 面向 ACC@0.5 的三个最小可证伪方向

**A. 先补“真实区别两个实例”的监督，优先于新融合层。** 从合法外部训练源的同图同类多实例提取成对 Query：外观相近而目标分别为左/右、前/后、靠近参照物/远离参照物；其中近远对必须在原始毫米深度内两个对象 ROI 均有充足有效像素、中心/主体内点中位数顺序与人工语义一致。用同一 RGB/IR/渲染深度与每一 Query 对应的真 RGB 框训练原生 Qwen3.6，保留现有最高分单步解码。对 `RoboRefIt` 这种自带 Query 的来源优先用原句；自造关系句仅当对象/参照对象标签与空间关系可验证。**与历史 G/U 的差别**：彼时约 98 条 RGBDT 新 Query 反复呈现，83 个辅助标签多数复制既有 GT 坐标可命中，且深度近远无经核准监督；本方案训练单位是一张图内的成对**竞争目标**、相反 Query、不同 GT 框，报告按独立场景/图组去重的“选错同类框→选对”净翻转。若只是增加常规 RGB 框，或关系 Query 在 RGB-only 与 RGBDT 下等效，不能归因于深度。

**B. 数值深度作为可信的对象关系证据，不把伪彩当毫米。** 当前 27B 输入的是固定渲染图，原始深度另行保留。拟从训练标注对象主体/掩码 ROI 计算有效比例、有效深度中位数、IQR、与参照物深度差；无效点（0、超量程）排除，边缘减少混合像素。AIC 主 PDF 规定深度 0.3–20m 且越小越近；`code/tools/depth_relation_tasks.py:35-60,136-166` 已有原始毫米统计和语义核对，可复用判据，但其审核标志 `visible_depth_order_reviewed=False` 提醒“原数值正确”并不保证“渲染后模型可读”。先做独立受控小任务：同一 RGB 图给两个明确 ROI，让模型读两者近远；分别用渲染深度图、带数值的局部证据、无深度图比较。仅在近远读数显著可靠且对 Query→框产生净增时引入主线。若生成数值证据依赖 GT 框，训练期可以，推理期必须由当前输入可计算的区域产生；绝不把测试 GT 或人工测试标注注入推理。

**C. 如数据增益不足，再试 RGB 锚定的“局部可靠性门”，而非三图等权早融合。** 结构假设：外观/语义主要由 RGB 主干确定，已空间对齐的 IR/D 只在 Query 相关 patch 通过很小的可学习残差影响单次 bbox 预测；门控输入包含 RGB 暗/模糊、IR 局部对比、D 有效像素比例/离散度以及该位置跨模态边缘错位。使用零初始化残差，只保证零门退回该模块所附加的明确基线；若基线仍输入原生三图，就不等于RGB-only。先在RGB-only或现有三图之一上定义清楚，再对合法外部Query+框训练并研究缺模态增强。RGBT-VGNet 的 `models/mmvg_fusion.py:1181-1188,1301-1338` 可借鉴照明+局部/全局可靠性思想，RDTTrack 的 `vit_ce_prompt.py:220-260` 可借鉴 RGB 锚定的小提示，但须重新设计**语言条件**和**传感质量**；现有代码没有这两个机制的完整组合，也没有直接支持Qwen3.6-27B的可插模块；共享视觉塔的模态路由、批处理与vLLM支持都需修改，因此工程成本高于普通语言LoRA，应后置。先只对坏 RGB/可读 IR 的切片提最小增量，不在所有图片强加复杂网络。若同条件全分母改错多于改对，或同源弱对齐/高无效深度组退化，应退回 RGB-only 或无该辅助模态的原生推理。

A中的成对数据若仍各自独立SFT，只改变数据覆盖，不自动形成对比损失；主报告增加明确候选判别辅助目标来检验这一机制。三方向分阶段推进：A检验监督是否命中错误机制；B 检验数值关系是否真的被模型使用；只有 A/B 失败原因明确是“模态有证据但主干未读”，才考虑 C。此顺序并非论文已证 AIC 可提升，而是本项目假设。

### 最小评价与推翻条件

冻结 Arm 2 ck500 k2.0 的逐题输出及同运行环境，比较 RGB-only、原生 RGB+IR+D、A、B、必要时 C；同一权重的关 IR/关 D/质量分层干预用于判断模态贡献，但关模态测试需与训练缺模态分布相容。保持完全相同的 Query、图像组、分母、分辨率和输出解析；报告 ACC@0.5 的**改对/改错 Query 与独立图组数**，另列 IoU 距 0.5 近的边界样本、小目标、同类实例、明确近远、弱光、深度无效及 RGB/IR 错位切片。City412 已被反复使用，适合机制诊断而非独立结论；半决赛可用合规新数据的独立图组/官方反馈确认。还需图组/序列级 bootstrap 避免同视频帧虚增样本量。

明确推翻：若深度关系二选一的正确率在遮掉 D 后不下降、在原始毫米核对过的反向关系对仍不能区分，就不能称模型使用了深度；若多模态总体净损失或仅在训练源上获益，就不应替换 0.8012 基线；若 IR 在明亮高对比 RGB 图造成稳定退化，质量门应学会关闭 IR，不能用“所有模态必须参与”要求强制加权。先检验最终框是否跨过 IoU 0.5，单纯语义解释更漂亮、框 mIoU 小幅变化或候选覆盖增大都不能替代 ACC@0.5。
