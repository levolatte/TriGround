# 结构研究修订：DINO联合定位退出默认主线

后续研究已形成[实例关系参与首次定位的新方案](../2026-10-25-structural-search/README.md)，补齐全部历史、区域状态与并行出框论文、方法源码及数据可行性；当前设计以该文为准。本文保留 DINO 默认主线被撤回的依据。

2026-10-25。**撤回本日稍早“GroundingDINO空间分支＋27B语义桥优先接管最终出框”的裁决。** 旧实验的原始输出已重新核对，详细原因见[联合判断失败复盘](../2026-10-25-dino-retrospective/README.md)。[原提案全文](dino-joint-proposal-20261025.md)保留为被审查的历史版本，其实施优先级不再生效。

当前仍追求结构性改变：让高细节空间表示和真实传感器信息直接参与目标选择，并让最终框损失训练这些表示。需要改正的是将这套目标预先绑定到DINO、默认其能接替主模型现有定位能力。

## 1. 什么证据改变了裁决

9月27日旧8B的完整联合流程为C直接框292/412、候选选择273/412、局部细化221/412。联合候选池中有47道额外可救的C错题，选择只救回10道却破坏29道；细化又净损52道。候选中保留C框，没有保留原来的正确决策。

10月1日的另一套工具接口为217/412，相对同一C纠正11道、破坏86道；开放搜索和自由框接口仍未救回初始池外73题。正式新接口SFT未运行，不能说训练后的方法已经失败；但也不能用“未来训练可能解决”支撑无条件投入。

这些不是当前27B或新联合网络的实验分数。它们否定的是此前选型中的推理跳跃：

- 有更多正确候选，不等于模型会可靠地选对。
- 可移动的定位槽，不等于学到了所有所指区域。
- 能读取隐状态、能反向传播，不等于保留了原模型的视觉决策能力。
- 能输出合法坐标，不等于模型理解了新坐标接口。
- 原始Depth或IR进入计算，不等于与正确主体绑定并带来收益。

[代码取证](../2026-10-25-dino-retrospective/code-forensics.md)、[CPU复算](../2026-10-25-dino-retrospective/metrics.md)、[独立反方审查](../2026-10-25-dino-retrospective/redteam.md)分别给出实际链路、逐题结果和新旧机制的区别。

## 2. 保留的结构研究目标

| 预测环节 | 仍值得改变的内容 | 本次撤掉的默认依赖 |
|---|---|---|
| 传感器表示 | 原始Depth数值、有效掩码与来源单位；IR保留二维特征 | 所有空间证据必须由DINO分支解释 |
| 模态交互 | 在RGB空间位置附近读取IR和Depth，使证据参与最终定位 | 将IR/Depth默认移出27B，再声称保留其多模态理解 |
| 目标条件表示 | 完整Query与场景共同形成目标条件，保留属性、参照和集合上下文 | 低细节RGB输入的Query隐状态已足够替代原决策过程 |
| 最终定位 | 学习连续框或目标区域，让几何损失直接训练表示 | 所指目标必须首先对应预训练检测器的对象槽 |
| 监督 | 真实目标、竞争实例、完整范围与框损失 | 单框匹配自然教会900槽形成完整对象和参照集合 |

这依然是视觉表示、跨模态交互和输出机制的改造。前轮辅助回答A/B可以作为监督对照，但不再替代结构研究。

## 3. 重点转向主模型内部的目标条件定位

**下一步优先设计以主模型完整多模态视觉判断为中心的连续定位结构。** 目标条件状态读取主模型自身的空间视觉特征，再结合必要的高细节与数值传感器特征预测所指区域；不先把主模型缩成低细节RGB语义编码器。

这是后续设计方向，尚不是完成的模型规格或已证实的优胜者。它的依据是减少对已有效视觉路径的剥离，并取消“所有指代目标首先属于外部检测对象集合”的必要条件，而非宣称一个简单四维MLP就足以定位。

已有[Qwen接口研究](qwen-interface.md)提供了可复用的源码基础：现役实际为`qwen3_5`实现，语言状态5120维、视觉状态1152维，patch16/merge2。视觉patch具有分组顺序，合并前特征不能直接reshape冒充原图网格；图像段、`image_grid_thw`、位置编码和几何逆变换必须对应。底层前向可读出Query隐状态，但这个事实只证明接口可用。

需要在完整结构设计中解决的核心问题有四个：

1. **空间读出。** 目标条件表示如何在保留正确空间索引的视觉特征上选择并形成区域；是否需要合并前高细节特征，而不是均值池化后直接回归四数。
2. **传感器绑定。** IR采用局部对应；Depth保持数值与valid。框内有有效深度不等于目标主体深度，不能用背景统计伪造近远监督。
3. **能力保留。** 生成框监督可作为训练期约束和独立对照，但不能宣称多任务训练必然不退化，也不引入未经训练的双头择优门控。
4. **监督覆盖。** 公开指代定位和真实多传感器数据需要覆盖实例、完整范围、参照及非典型区域；已有226对、157张图适合作域适配，不足以默认从头学齐新接口。

采用最终目标框监督时，损失必须作用于实际输出结构，并能训练相关视觉/语言适配参数。保留全局RGB坐标，不再依赖模型同时切换全局与局部的文字坐标协议。

## 4. DINO联合定位仍可作为完整竞争假设

原方案确实修掉了一些旧机制：它没有冻结JSON候选硬上限；连续回归避免了局部文字坐标协议；联合损失区别于冻结C选ID。这些差异应准确保留。

但其合理表述应是：

> 尝试把27B的图文条件表示迁移给三传感器定位器，通过联合训练学习更好的最终区域预测。

它不能预先表述为“保留27B视觉理解，由更可靠的空间专家接管定位”。

若后续选择实施这一竞争结构，原提案中的900槽初始化、BERT路径、语义桥和连续框损失可作为设计材料；应称“定位槽”，不能把槽数当真实实例数。原图文top-k初始化与detach保留，Qwen在decoder中接入，连续框可以离开初始位置，但能否学会仍是待证假设。

去Qwen桥的同数据重训仍有直接价值：若不差，则桥是多余成本。专用三传感器定位网络也可以独立竞争；不能为了保住27B或DINO的名字再堆接口。

## 5. 比较完整预测器，裁决最终净收益

当前应面对的是三个完整预测器，而非默认先实施原方案C：

| 预测器 | 要回答的问题 |
|---|---|
| 等数据、相当视觉输入的27B直接框 | 新收益是否只是训练数据或可见细节增加 |
| 主模型内部目标条件连续定位 | 沿用其多模态视觉表示、改变空间读出与框损失是否有益 |
| 外部DINO定位器＋Qwen桥 | 两套预训练系统重新对接，能否胜过原有决策路径 |

具体训练规模与计算安排取决于正式结构和可用数据，本轮不虚构实施预算。新结构与公平训练对照应从相同可比的基座条件组织；现役Arm2保留为冻结成绩基线，历史混合数据的重叠问题不能省略。

最终比较使用未反复调参的场景/序列留出数据，报告单一输出框的ACC@0.5、按场景的救回/破坏、实例/范围/小目标分层，以及输入细节和计算成本。City400和历史94条仍为开发诊断，不能重新切一次就称独立验证。

候选或槽的覆盖用于解释“有没有可用位置”，最终选框用于判断系统效果。正确/缺失/错配模态的干预用于解释依赖，同数据去模态重训用于评价有益使用。接口、坐标及梯度检查只排除实现错误，不作为结构成功的证据。

主动观察与RL仍是不同研究方向，但不会因DINO主线被撤回就自动升格。旧Agent已经表明，工具可调用和动作可解析不等于获得有效新证据；完整训练策略及最终全局框需要自己的证据。[主动观察专题](active-rl.md)保留方法研究，不能据此恢复旧停用流程。

## 6. 仍有效的论文与源码研究

上一轮阅读的12篇核心工作与方法源码不因选型错误而作废；应修正它们支持的结论范围。

| 研究链 | 仍有效的材料 | 不应跨越的推断 |
|---|---|---|
| 传感器融合 | RGBT-VGNet、DualVision、RDTTrack中的二维对应、区域监督及深度处理 | 相邻任务的效果不保证本项目三模态增益 |
| 对象与连续定位 | Groma、Grounding DINO、MDETR的表示、匹配及框损失 | 检测对象性不等于任意指代区域；GT注入不能冒充推理覆盖 |
| 高细节连接器 | Cambrian、Eagle的方法与公开训练实现 | 更复杂融合没有普遍胜过拼接；论文最优配方不等于公开默认脚本 |
| 显式关系 | SVCR的目标—参照关系动机 | 单框和错邻居对不自动提供参照真值；无实现部分仍是论文证据 |
| 主动观察 | DeepEyes、Pixel-Reasoner、LFPC及反事实检查 | 工具调用率和额外推理步骤不能证明利用了新图像 |
