2026-10-25。审读对象为 [SVCR / ECCV 2026 论文正式 PDF](https://arxiv.org/pdf/2607.04638) 共 25 页（正文 1–18，补充材料 19–25），以及[作者标为官方实现的仓库](https://github.com/quiet5daxis/SVCR)。截至本次检查，仓库只有 `.gitignore` 与约 97 字节的 README，无模型、训练、数据或推理源码。因此下面是**完整论文与附录核验**，不是源码复现审计；对论文未写清的算法细节不作假定。已把 pp.2/5/8–9/11–13/20–23/25 渲染核对图、公式和表。

## 对本赛的结论

SVCR 最值得迁移的是**保持「目标对象」和「目标—参照物关系」为不同表征单元，并分别对齐语言**。本赛有真实 bbox 标签和三路传感器，应该把它接到 RGB 锚点三传感器特征之后，使用 **有方向的目标→参照物关系分数** 来辅助已有直接框头，针对相似实例、序数和参照物关系进行监督。不要照搬其弱监督伪正例、YOLOv3 的 17 anchor、SpaCy 首名词短语、从 RGB 猜出的 DepthAnything 深度，或 p.9 的对称关系聚合。它解决的是**候选之间如何按关系作决定**，不是 RGB/IR/Depth 的传感器配准机制。

## 论文实际张量与计算

**视觉入口，pp.5–6 Fig.2、式(1)。** 冻结 YOLOv3/DarkNet-53，按 objectness 选最高的 `K=17` anchor，提取 `A∈R^{K×D}`，含多尺度检测头特征。再从预训练 DINOv2-base 与 DepthAnything-v2-small 等基础模型取辅助特征 `F={f_j}`，用基于 anchor 与各来源特征的 softmax 动态路由得 `ã_i=a_i+Σ_j α_ij f_j`。文中“DINO + Depth”里的 **Depth 是 DepthAnything 从单张 RGB 估计的特征**；实验输入只有 RGB，与本赛真实 16 位深度传感器不是一回事，也没有红外。

**文本入口，pp.6–7 式(2)–(4)，补充 p.19/22–23。** GloVe 初始化词向量，LSTM 后接若干 self-attention；token 注意力池化得完整句向量 `s∈R^D`。spaCy `en_core_web_lg` 找第一个 noun chunk 并平均 span token 得主语对象向量 `s_c∈R^D`；没有 noun chunk 就用完整句。训练时最多 15 token。作者在 RefCOCOg val 将 spaCy 首短语与 GPT-4.1-mini 提取对比，exact match 75.5%、token F1 0.886；这支持它在该数据集可用，也同时意味着约四分之一的 exact 主语边界不一致。本赛长 Query、关系嵌套与序数不能直接用此启发式截断。

**一元对象表征 UOR，p.7–8 式(5)–(7)。** 设 `N=100` 个可学习全局语义基向量 `P∈R^{N×D}`；每个 `ã_i` 对 P 点积 softmax，得到语义投影 `a_i^una=Σ_n γ_in p_n`，再与原 anchor 特征作逐通道 sigmoid 门控，形成 `â_i`。这就是 `UOR∈R^{K×D}`，不是以物体类别手工定义的属性表。`||BBᵀ−I||²_F`（B 为单位化 P）鼓励基向量多样。它仍是每个 anchor 各自的对象表征。

**二元关系表征 PRR，p.8 式(8)–(9)。** 对所有**有序** `(i,j)` 形成 `r_ij∈R^D`，故 `PRR∈R^{K×K×D}`。输入是 `[ã_i,ã_j,δ_ij]`，其中 `δ_ij` 是 8 维几何描述的 MLP：`[Δx,Δy,log(w_j/w_i),log(h_j/h_i),IoU,d,cosθ,sinθ]`；另一个 sigmoid 标量 `w_ij` 调整关系强度。顺序与几何符号使 `r_ij` 和 `r_ji` 可不同。计算量与 K² 成正比；K=17 只有 289 对，K 大或直接用全部高分辨率 patch 会迅速放大。

**语言对齐与训练，pp.8–9 式(10)–(15)。** 一元分数 `u_i=â_iᵀs_c`；二元分数 `v_ij=r_ijᵀs`。二者分别做 anchor 内与 K² pair 内 InfoNCE，**没有 GT bbox**，使用高匹配分的伪正例；再加语义基多样性损失及 `L_cons=−log Σ_{i∈TopK(u)}v_pair(i)` 的层级一致性损失。论文 p.8 仅定义了一元伪正例 `i*`；p.9 式(13)的二元分子写 `r_{i*}`、分母展平 K²，却未解释对应的参照物 `j*` 如何选择；式(14)也没有写 `v_pair` 如何归一或 TopK 的数值。无源码可核，这两处不能当成可直接重写的完整算法。若在本赛有 GT 框，继续使用这套伪标签反而浪费强监督。

**推理，p.9 式(16)–(18)。** 对 anchor i，把 `logsumexp_j v_ij` 与 `logsumexp_j v_ji` 平均为**对称**关系置信，再同一元 `u_i` 以固定 `λ=0.6` 加权；选分数最大 anchor，由检测头解框。尽管 `r_ij` 本身有方向，最终同时汇集 outgoing 和 incoming 会弱化「目标是左边的 A」与「目标是 A 左边的 B」的角色差别。论文没有针对这一对称化的角色混淆消融。因此本赛应保留有向 `target i → reference j`，不照搬对称分数。

## 迁到本赛有框三模态定位的做法

将它当作 **QTS-Grounder 融合特征后的关系判别头**，不重复一个弱监督网络。RGB 锚点的视觉特征先由 `sensor-architecture.md` 中的 RGB/IR/原始 Depth 对齐门控得到；语言仍保留整句。由同一 Grounder 的密集空间头抽取 `K` 个**模型预测**的对象特征及框，训练 GT 只用于与这些框做 IoU 匹配和计算损失；若候选未覆盖目标，记为定位失败并优化预测框，不注入 GT 候选或构造虚假的正确关系对。候选对象向量 `o_i` 对 Query 主语向量做一元匹配；有序关系向量可写成

```text
g_ij = [Δx/W, Δy/H, log(w_j/w_i), log(h_j/h_i), IoU, 方向/距离,
        Δz_ij(仅两个主体深度都有效时), depth_valid_i, depth_valid_j]
r_ij = MLP([o_i,o_j,g_ij])          i ≠ j
u_i = <o_i,q_subject>
v_ij = <r_ij,q_relation> + <o_j,q_reference>
S_i = u_i + α(Query) · logsumexp_{j≠i}(v_ij/τ)
L = 1[目标被预测候选覆盖]·CE(S_i,匹配目标i*) + L1(B_i*,GT) + (1−GIoU(B_i*,GT))
```

`i*` 始终由模型预测候选与 GT 的匹配产生；未覆盖目标时只用定位损失推动预测框，不给关系头伪造正例。

`q_subject/q_relation/q_reference` 可由三个可学习 Query slot 对完整英文 Query 做注意力得到，不依赖固定首名词短语；训练监督直接来自 GT 目标框。参照物 j 未标注时作为潜变量由 `logsumexp` 汇集，不凭空生成“参照物真值”。对于已核实参照物框的小子集，可另加 j 的 CE 做诊断，不混同全数据。关系词“左/右、前/后、旁边、最近”要保持 i→j 的方向；Depth 差值只在两个**主体区域**均有可信有效深度时进入，未知则有独立缺失标记，不把矩形背景中位数当主体距离。没有明确参照关系的 Query 令 `α(Query)` 通过训练压低，避免所有句子被强迫寻找某个物体。

这个头在**单次前向内部**产生对象与关系联合分数，仍直接输出一框；不恢复已退役的多步 EGM/Locate 流程。它的限制也明确：若候选没有覆盖目标，关系头无法救；若 Query 的参照物在候选外、被遮挡或 Depth 缺失，`logsumexp` 可能选择显著但无关的 j。因此保留原密集直接框的覆盖指标，并在训练与评估中单列“目标覆盖”和“关系决策正确率”。

### 最小判别实验

使用同一三模态特征、同一候选列表、同一 GT 框及优化预算，比较 `u_i` 一元评分、把 pair 聚合回 `o_i` 的 unary 关系、上述有向 PRR 三臂；只在带参照/序数的可靠 Query 上预设主要效应，同时报告总体 `ACC@0.5`、按场景配对救回/破坏、候选目标覆盖、参照物 attention 位置。对**已核实**左右/远近对调的成对 Query，交换关系词后目标应随之改变，且无有效深度时不能仅因数值 0 决定“最近”。若只提高训练场景关系题、跨场景无收益或参照物位置普遍错误，应回查 Query/框/候选和训练对齐，而不是套用论文 λ=0.6 或继续增大 K。
