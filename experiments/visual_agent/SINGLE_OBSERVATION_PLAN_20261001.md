## 1. 路线决定与反思

结束当前全量、多轮、候选编号重决策路线。保留工具、模型和历史证据；不扩教师、不训练1064行课程、不补旧控制器动作配额。唯一后续候选是无训练、固定程序取证、原生坐标输出的短方案。失败后不转入轨迹训练补救。

我先前的关键错误是把工具返回真实图像、动作格式正确和训练流程跑通，当作逐步接近定位增益的证据。真正应检验的是：新增观察是否改变了正确的目标判断，以及纠正数是否超过破坏数。旧固定inspect→GT终局监督没有充分教会自主取证和对象绑定，这一问题由本对话先前方案引入，不能全部归责后续分支。上一轮审计还漏检了复习行的实际图像块，现已补正。

保留事实边界：新接口217/412是C权重未训练的接口结果；新课程从未训练。不能称新SFT失败，也不能由此证明所有视觉工具增强无效。但相比C的292/412，11纠正/86破坏已足以否定当前系统继续优先占用竞赛资源。

## 2. 文献核查

- [IVT v2，2026-07-06](https://arxiv.org/html/2606.13156v2)：79.6→82.0使用真值选轨迹最佳步；作者测试的可部署停止/选择规则未保住收益。它研究的是预测框回绘后的自我修正，不能直接否定新增独立IR/Depth观察；却明确削弱了“训练后让模型自己挑最佳框即可”的依据。若先前将82.0当作真实部署增益，撤回该解读。
- [List Items One by One / SoM-LLaVA v2](https://arxiv.org/html/2404.16375v2)：区分读取标号、识别对象、标号与对象关联；提出专门数据训练第三项。不是对本项目Qwen3-VL的直接诊断，但支持“看懂衣服不等于绑定正确框”的机制解释。它不是原始SoM论文，引用时不混称。
- [Pixel Reasoner](https://arxiv.org/html/2505.15966v1)：视觉操作轨迹预热，加结果与探索激励训练；直接蒸馏也可能产生绕过工具的轨迹。证明工具能力可研究，不能证明当前课程充分或少量续训必然提分。其任务、模型和预算与本赛题不同。

## 4. 唯一研究问题与三个条件

假设：一次确定性的细节/辅助模态观察，能在不学习新控制协议的情况下使冻结C增加净正确数。新增图仍属于输入分布变化，不保证保存C能力。

| 条件 | 预测方法 | 可回答的问题 |
|---|---|---|
| N0 | 原来源全图、原完整Query、原生prompt与0–1000 bbox_2d JSON | 冻结C参照 |
| N1 | N0加一批最多两个RGB区域细节，然后一次原生定位 | 该固定细节增强整体是否有用 |
| N2 | 与N1完全相同RGB区域，加对应IR细节，或适用时的可靠Depth摘要 | 辅助证据在N1之上是否有增量 |

“单次”指程序一次组装证据、模型一次增强预测；若区域需要C初始框，初始C推理是额外成本，必须计入。无候选编号终局、自由工具选择、工具循环、自信度裁判、五框择优或局部坐标输出。最终始终是原始RGB全图坐标。

N2相对N1改变的是辅助观察包，最多能声称整个包的增益；没有额外对照时不进一步声称究竟由图像、文字或新增词元造成。N2不是首次加入IR/Depth。

## 5. 预先固定的最小取证规则（不读取GT）

首版使用已有候选/查询解析缓存，复用已有检测器与配准；不增加模型和视觉教师。执行前确认缓存由图像与Query产生，未使用目标GT筛选。来源不清的候选不能用作自动策略输入。

1. RGB触发：C框面积不超过全图10%，或Query命中固定外观细节词表（颜色、服饰、花纹、姿态）。词表仅以训练来源小批确定并保存；不根据dev逐题添词。
2. 区域一为C框；区域二为现有target候选中与C框IoU<0.5、RGB检测分最高的竞争框；同分按全图xyxy排序。没有竞争框时只用区域一。不让模型输出或选择ID。两区域各向四周扩展原框宽高的25%并裁到图边；不画标签或候选框。固定最多两个，避免重建候选图册。该规则不保证覆盖真实目标，承认其搜索能力有限。
3. 细节以原RGB坐标范围说明来源，保留完整原图和Query；明确“附图只看细节，位置/顺序以第一张RGB全图为准，返回其坐标”。不把区域称作“正确目标”或编造对象描述。不将初始C答案文本喂入增强模型。
4. N2在相同RGB证据上：明确相机近远Query且存在已校准原始Depth、有效主体掩码与可靠配准时，用Depth摘要；否则有可靠配准IR就加相同区域IR；否则N2=N1。相机近远词表排除“靠近另一物体”等物体间关系，near/behind单词本身不足以触发米制距离结论。
5. Depth先检查真实编码：已知单位才给米；只有相对编码时不声称绝对距离。无可靠主体对应则不输出距离判断，不取背景混入的整个框中位数冒充主体。首版只用已有且已验证的主体测量，缺少就不建新分割/配准工程。输出区域全图坐标、有效覆盖率、中位数及四分位范围；程序仅在区域测量区间有明确分离时表达相对次序，重叠则不判定。该信息是测量摘要，不是目标标签。
6. RGB未触发且无可用辅助证据时直接复用N0；只有辅助证据时，N1=N0，N2可一次提供辅助观察。是否增强在模型输出前确定，不能按GT或生成答案决定回退。增强输出非法则按既有评分失败计入，不事后择优。

以上数值是首版资源约束下的固定工程选择，不是文献证明的最优值。训练来源小批只修可见的输入/区域错误；若该规则覆盖不足，报告覆盖不足并停止，不展开候选生成研究。

## 6. 数据与评价顺序

沿用evidence_decision_20260930/data的dev40_manifest、city412_eval_manifest、final80_manifest，不重抽有利样本。仅检查ID/图组，不读取final80标签或评分。

1. 训练来源8–12题输入检查：不同模态/编码、竞争区域、序数关系；记录实际图像块和processor网格，目视区域。不是精度筛选，不据GT手选区域。
2. 开发40：N0/N1/N2全分母配对。至少一臂相对真实N0净增≥2题且无坐标/图像系统性错误，才推进；并列优先N1。同一分数更低成本优先。小样本漏掉弱信号是有意接受的资源取舍，不作显著性结论。冻结一个赢家及完整规则，不做多轮开发调参。
3. City412：只跑冻结赢家与可复用的N0参照，失败计入412。若赢家N2，可在预算内补N1以解释IR/Depth增量；没有该同域消融则不宣称City收益由辅助模态导致。
4. City净增≤0停止；+1～3为弱信号停止；+4～7记录有限信号、本次仍不追加训练或继续调优；≥8且至少三个图组有正向贡献、单组贡献不超过全部净正向组贡献一半，才启用最终80一次确认。门槛仅用于资源分配。
5. 最终80只评冻结赢家和N0，一次；总体净增>0且至少两个图组有纠正、City子集无净退化，才列为可保留的简单候选。否则证据不足，不修改规则后重测这80。不据此承诺赛榜收益。
